# 11. Container With Most Water

**模式标签**：对撞双指针

- **难度**：Medium
- **标签**：双指针、贪心
- **链接**：https://leetcode.cn/problems/container-with-most-water/

## 题目描述

给定一个数组表示垂线高度，找出两条线与 x 轴围成的容器能容纳的最大水量，不能倾斜容器。

## 关键思路

**"求最大/最小" 想双指针**：区间两端往内收缩 + 贪心移动

> 面积取决于较短的高度 × 宽度。每次移动较短的那一侧，因为移动较高侧只会让面积变小（宽度-1，高度受限于短板）。在收缩过程中记录最大面积即可。

## 代码实现

```python
class Solution:
    def maxArea(self, height: List[int]) -> int:
        l, r = 0, len(height) - 1
        ans = 0
        while l < r:
            ans = max(ans, min(height[l], height[r]) * (r - l))
            if height[l] < height[r]:
                l += 1          # 矮的那侧往内挪，可能找到更高的
            else:
                r -= 1
        return ans
```

## 复杂度分析

- 时间复杂度：O(n)
- 空间复杂度：O(1)
