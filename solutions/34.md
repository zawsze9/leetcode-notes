# 34. Find First and Last Position of Element in Sorted Array

**模式标签**：二分查找（lower bound / 插入点）+ 变式：偏置二分找两端边界

**母题**：#35 Search Insert Position（lower-bound 引擎 + 偏置方向）

**状态**：AC且最优（纠错后通过）

**完成方式**：纠错后通过

- **难度**：Medium
- **标签**：数组、二分查找
- **链接**：https://leetcode.cn/problems/find-first-and-last-position-of-element-in-sorted-array/

## 题目描述

**非递减**有序数组（可有重复元素），找出 target 在其中的**开始和结束位置**；不存在返回 `[-1, -1]`。要求 **O(log n)**。

示例：`nums = [5,7,7,8,8,10]`，target=8 → `[3,4]`；target=6 → `[-1,-1]`。

## 关键思路

先一句话定义答案：左边界 = 最左副本下标；右边界 = 最右副本下标。

⭐ 核心转折：**命中不是终点，是收缩的原料**。v1 的错误正在于此——命中即返回，把循环中途的窗口边界当答案。

不变量时机回顾（#35 认证地图）："lo 左全 `<`、hi 右全 `>`"只在**循环退出**（lo=hi+1 夹逼闭合）那一刻成立；命中发生在**循环中途**，窗口内部还有未认证区，副本的边界此刻未知。

信息量论证：一趟二分的全部产出是**一个收敛点**；答案需要**两个端点** → 两次带偏置的二分：

| 搜什么 | 命中时的动作 | 等值元素划入 | 收敛到 |
|--------|-------------|-------------|--------|
| 左边界 | 记录 mid，继续 `hi = mid - 1` | 右侧 | 最左副本 |
| 右边界 | 记录 mid，继续 `lo = mid + 1` | 左侧 | 最右副本 |

## 代码实现

### 你的 AC 解法（两遍偏置二分）

```python
class Solution:
    def searchRange(self, nums: list[int], target: int) -> list[int]:
        lo = 0
        hi = len(nums) - 1
        ans = [-1, -1]
        while lo <= hi:
            mid = (lo + hi) // 2
            if target > nums[mid]:
                lo = mid + 1
            elif target < nums[mid]:
                hi = mid - 1
            elif target == nums[mid]:
                ans[0] = mid
                hi = mid - 1              # 往左压：等值划入右侧
        lo = 0
        hi = len(nums) - 1
        while lo <= hi:
            mid = (lo + hi) // 2
            if target > nums[mid]:
                lo = mid + 1
            elif target < nums[mid]:
                hi = mid - 1
            elif target == nums[mid]:
                ans[1] = mid
                lo = mid + 1              # 往右压：等值划入左侧
        return ans
```

结构性优点：空数组（hi=-1 两轮全跳过）和不存在（ans 保持初值）都被骨架天然兜住，无特判。可打磨点：两段 while 逐行重复（见参考解 1/2 消重）。

### 参考解 1：抽 helper 跑两遍（消重复，同 O(log n)）

```python
class Solution:
    def searchRange(self, nums: list[int], target: int) -> list[int]:
        def search(left_bias: bool) -> int:
            lo, hi = 0, len(nums) - 1
            pos = -1
            while lo <= hi:
                mid = (lo + hi) // 2
                if nums[mid] < target:
                    lo = mid + 1
                elif nums[mid] > target:
                    hi = mid - 1
                else:
                    pos = mid                 # 命中先记录，不返回
                    if left_bias:
                        hi = mid - 1          # 左搜：等值划右
                    else:
                        lo = mid + 1          # 右搜：等值划左
            return pos

        return [search(True), search(False)]
```

一个函数、一个布尔偏置，两行差异被参数吸收。

### 参考解 2：lower_bound 版（无命中分支，单函数）

```python
class Solution:
    def searchRange(self, nums: list[int], target: int) -> list[int]:
        def lower_bound(t: int) -> int:
            lo, hi = 0, len(nums) - 1
            while lo <= hi:
                mid = (lo + hi) // 2
                if nums[mid] < t:
                    lo = mid + 1
                else:                     # >= t：等值也划右
                    hi = mid - 1
            return lo                     # 第一个 >= t 的下标

        left = lower_bound(target)
        if left == len(nums) or nums[left] != target:
            return [-1, -1]
        return [left, lower_bound(target + 1) - 1]
```

⭐ 关键换算：**等值段的右端 = 下一个值的左端减一**。`lower_bound(target)` 收敛到最左副本；`lower_bound(target + 1) - 1` 收敛到最右副本——全程没有"命中"分支，判断被压到 `<` 一处。

### 参考解 3：bisect 库函数版（最简，同 O(log n)）

```python
from bisect import bisect_left, bisect_right

class Solution:
    def searchRange(self, nums: list[int], target: int) -> list[int]:
        left = bisect_left(nums, target)
        if left == len(nums) or nums[left] != target:
            return [-1, -1]
        return [left, bisect_right(nums, target) - 1]
```

`bisect_left(a, x)` = 第一个 `>= x` 的下标（lower_bound 封装）；`bisect_right(a, x)` = 第一个 `> x` 的下标。等值段恰好是 `[bisect_left, bisect_right - 1]`。

### 手动推演

nums=[5,7,7,8,8,10]，target=8：

| 轮 | 左搜（命中划右） | 右搜（命中划左） |
|----|-----------------|-----------------|
| 1 | lo=0,hi=5,mid=2(7)<8 → lo=3 | 同左 → lo=3 |
| 2 | lo=3,hi=5,mid=4(8) 命中 → ans[0]=4, hi=3 | 命中 → ans[1]=4, lo=5 |
| 3 | lo=3,hi=3,mid=3(8) 命中 → ans[0]=**3**, hi=2 | lo=5,hi=5,mid=5(10)>8 → hi=4 |
| 退出 | lo=3>hi=2，ans[0]=3 | ans[1]=4 |

返回 [3,4] ✓。左搜的最后一压（4→3）正是"等值划右"在收最后一个副本。

target=6：两轮全程无命中，ans 保持 [-1,-1] ✓。

## 复杂度分析

| 方法 | 时间 | 空间 |
|------|------|------|
| 你的 AC（两遍偏置二分） | O(log n) | O(1) |
| helper 版 / lower_bound 版 / bisect 版 | O(log n) | O(1) |

四个版本同复杂度，差异只在代码组织；必须现场手写时用偏置/lower_bound 模板，日常解题 bisect 最短。

## 错误记录

### 初始错误代码（v1：命中即返回窗口边界）

```python
while lo<=hi:
    mid=(lo+hi)//2
    if target>nums[mid]:
        lo=mid+1
    elif target<nums[mid]:
        hi=mid-1
    elif target==nums[mid]:
        return [lo,hi-1]        # ⭐ 循环中途的窗口边界 ≠ 答案边界
```

### 错误分析

| 问题 | 说明 |
|------|------|
| ⭐ 命中即返回，用中途窗口当答案 | 不变量"lo 左 `<`、hi 右 `>`"只在**循环退出**时成立；命中是中途，窗口内部未认证，副本边界未知 |
| 一趟二分产两端 | 信息量不匹配：一趟收敛出一个点，答案需要两个端点 |
| 巧合逻辑 | 窗口未动的用例蒙对；[2,2] t=2 返 [0,0]（期望 [0,1]）；t=10 返 [5,4]——起点 > 终点自相矛盾 |

### 教训

| 场景 | 做法 |
|------|------|
| 不变量使用时机 | 只在循环退出（lo=hi+1）引用两侧认证；中途窗口内部一律当未知区 |
| 答案是区间 | 两个端点 = 两次偏置搜索；或 lower_bound(target) + lower_bound(target+1) - 1 |
| 命中的两种用法 | 要"存在性/插入点"→ 命中即返回（#35）；要"边界"→ 命中即记录、继续收缩（#34） |
| 巧合逻辑识别 | "部分用例对、部分错"→ 立刻找最小反例推演，别打补丁 |

## Python 概念备忘

**bisect 模块**（C 实现，比手写略快）：

| 函数 | 语义 | 返回 |
|------|------|------|
| `bisect_left(a, x)` | lower_bound | 第一个 `>= x` 的下标 |
| `bisect_right(a, x)` | upper_bound | 第一个 `> x` 的下标 |

等值段 = `[bisect_left(a,x), bisect_right(a,x)-1]`；不存在时 `bisect_left == bisect_right`，区间为空——"存在性"两函数一比便知。
