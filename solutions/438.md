# 438. Find All Anagrams in a String

**模式标签**：定长滑动窗口 + 频率数组
**状态**：思路正确但不能AC

- **难度**：Medium
- **标签**：哈希表、字符串、滑动窗口
- **链接**：https://leetcode.cn/problems/find-all-anagrams-in-a-string/

## 题目描述

找到字符串 `s` 中所有 `p` 的字母异位词子串的起始索引，顺序任意。

## 关键思路

**定长滑动窗口 + 频率数组比较**：p 只含小写字母时，用长度为 26 的数组替代哈希表做字符计数，窗口每滑动一步就更新两个字符的计数，O(1) 完成移动。

> 字母异位词本质是字符频率相同。不必每个窗口都重新统计，用滑动窗口"进来一个、出去一个"增量更新即可。用 list 的 `==` 比较两个长度为 26 的数组，比 set 或 Counter 都高效。

## 代码实现

```python
class Solution:
    def findAnagrams(self, s: str, p: str) -> List[int]:
        if len(p) > len(s):
            return []

        p_cnt = [0] * 26
        w_cnt = [0] * 26
        a = ord('a')

        for c in p:
            p_cnt[ord(c) - a] += 1

        # 初始化第一个窗口
        for i in range(len(p)):
            w_cnt[ord(s[i]) - a] += 1

        ans = []
        if w_cnt == p_cnt:
            ans.append(0)

        # 滑动窗口：右进左出
        for i in range(len(p), len(s)):
            w_cnt[ord(s[i]) - a] += 1               # 新的右字符进入窗口
            w_cnt[ord(s[i - len(p)]) - a] -= 1      # 旧的左字符移出窗口
            if w_cnt == p_cnt:
                ans.append(i - len(p) + 1)          # 窗口起始索引

        return ans
```

## 复杂度分析

- 时间复杂度：O(n)
- 空间复杂度：O(1)（两个固定大小的 26 元素数组）

## 错误记录

### 初始错误代码

```python
class Solution:
    def findAnagrams(self, s: str, p: str) -> List[int]:
        ans = []
        for i, v in enumerate(s):
            l, r = i, i + len(p) - 1
            if r > len(s) - 1:
                break
            flag = i
            tmp = list(p)
            while flag >= i and flag <= r:
                if s[flag] not in tmp:
                    break
                else:
                    tmp.remove(s[flag])
                flag += 1
                if flag == r + 1:
                    ans.append(i)
        return ans
```

### 错误分析

| 问题 | 说明 |
|------|------|
| **`not in` 是 O(m) 列表扫描** | 每个窗口内对每个字符都调用 `s[flag] not in tmp`，list 的 `in` 是线性扫描，每次 O(m) |
| **`tmp.remove()` 是 O(m)** | 删除后还要移动后续元素，嵌套在 while 里，每个窗口 O(m²) |
| **`tmp = list(p)` 每个窗口都复制** | 每轮外层循环都从 p 重新拷贝一份列表，额外 O(m) |
| **整体 O(n × m²) 必然超时** | n 和 m 可达 3×10⁴，m² 就是 9×10⁸ 量级，无法通过 |

### Bug 推演：`s = "cbaebabacd", p = "abc"`

```
外层 i=0: tmp=['a','b','c']
  flag=0, s[0]='c' in tmp ✓, tmp.remove→['a','b']
  flag=1, s[1]='b' in tmp ✓, tmp.remove→['a']
  flag=2, s[2]='a' in tmp ✓, tmp.remove→[]
  flag=3=r+1 → ans=[0]

外层 i=1,2,... 每个窗口都复制 tmp、逐个 remove...
```

### 教训

| 场景 | 正确操作 |
|------|---------|
| 字母异位词匹配 | 用频率数组 O(1) 增删，而非 list 的 remove / in |
| 定长窗口移动 | 增量更新（进一个右、出一个左），避免每窗口重新计算 |
| 小写字母限制 | `[0]*26` + `ord(c) - ord('a')` 是最高效的选择 |
