# 2. Add Two Numbers

**模式标签**：哨兵节点 + 进位模拟

**状态**：思路正确但不能AC（边界处理混乱）

- **难度**：Medium
- **标签**：链表、数学、模拟
- **链接**：https://leetcode.cn/problems/add-two-numbers/

## 题目描述

两个非空链表表示两个非负整数（数字逆序存储），求两数之和，同样以链表返回。

## 关键思路

**单循环 + 进位 + None 视为 0。** `while l1 or l2 or carry` 让循环条件承载全部情况：任一遍历未完或仍有进位就继续。循环体内 `v = carry + l1.val(若存在) + l2.val(若存在)`，存个位、进十位，下一轮自动消费。

> 不需要算长度、不需要交换链表。`None` 当 0 参与运算，天然处理不等长。

## 代码实现

```python
class Solution:
    def addTwoNumbers(self, l1: Optional[ListNode], l2: Optional[ListNode]) -> Optional[ListNode]:
        dummy = ListNode()            # 哨兵节点
        cur = dummy
        carry = 0

        while l1 or l2 or carry:      # 循环条件覆盖所有情况
            v = carry
            if l1:
                v += l1.val
                l1 = l1.next
            if l2:
                v += l2.val
                l2 = l2.next

            cur.next = ListNode(v % 10)   # 存个位
            carry = v // 10               # 进十位
            cur = cur.next

        return dummy.next
```

### 手动推演：`l1 = [2,4,3], l2 = [5,6,4]`（即 342 + 465 = 807）

```
carry=0
第1轮: v=0+2+5=7   → 存7, carry=0   链: 7
第2轮: v=0+4+6=10  → 存0, carry=1   链: 7→0
第3轮: v=1+3+4=8   → 存8, carry=0   链: 7→0→8

答案 [7,0,8] = 807 ✓
```

### 边界：`l1 = [9,9,9,9,9,9,9], l2 = [9,9,9,9]`

```
最后几轮:
... 链: 8→9→9→9→0→0→0
最后: l1 还有2个节点, l2 已空(None当0), carry 持续传递
最后一轮后 carry=1 但 l1、l2 都空 → 循环条件 carry 仍真 → 新建节点存1

答案: [8,9,9,9,0,0,0,1]
```

## 复杂度分析

- 时间复杂度：O(max(m, n))
- 空间复杂度：O(max(m, n))（输出链表长度）

## 错误记录

### 初始错误代码（要点）

```python
# 算 m、n 长度 → 交换保证 l1 更长 → 三段循环分阶段处理
# 进位逻辑写了三遍（主循环 / if l1.next is None 分支 / 第二个 while）
# 循环内 if l1.next is None: break 之后还要在外面补逻辑
# 残留 print(l1, l2) 调试代码
```

### 错误分析

| 问题 | 说明 |
|------|------|
| **分支爆炸** | 先算长度、再交换链表、再分三段循环、每段再塞 if —— 组合情况多，必然漏边界 |
| **重复代码** | 进位处理写了 3 遍，改一处漏一处 |
| **break 割裂逻辑** | `if l1.next is None: break` 跳出后还得续写处理，两段代码共享状态极易出错 |
| **算长度交换绕远** | 为防 `l2.val` 崩溃去保证 l1 更长，不如 `if l2:` 存在才取值，None 当 0 |
| **残留 print** | 调试代码未清理 |

### 教训

见专题笔记：《链表边界处理》—— 哨兵节点 + 循环条件承载所有情况 + None 视为 0 + 进位在循环内消费。
