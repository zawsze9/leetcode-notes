# 283. Move Zeroes

- **难度**：Easy
- **标签**：双指针、数组
- **链接**：https://leetcode.cn/problems/move-zeroes/

## 题目描述

给定一个数组，将所有 0 移到末尾，保持非零元素的相对顺序。必须原地操作，不能复制数组。

## 关键思路

 快慢双指针交换
一次遍历，原地操作

> `slow` 指向下一个非零元素应该放置的位置，`fast` 扫描数组。遇到非零就与 `slow` 交换并前移 `slow`。`fast` 扫过的位置，`slow` 左侧都是非零且保持原序，`slow` 到 `fast` 之间都是零。

## 代码实现

```python
class Solution:
    def moveZeroes(self, nums: List[int]) -> None:
        """
        Do not return anything, modify nums in-place instead.
        """
        slow = 0                              # 指向下一个非零应放的位置
        for fast in range(len(nums)):
            if nums[fast] != 0:
                nums[slow], nums[fast] = nums[fast], nums[slow]
                slow += 1
```

## 复杂度分析

- 时间复杂度：O(n)
- 空间复杂度：O(1)
