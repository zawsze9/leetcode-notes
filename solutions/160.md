# 160. Intersection of Two Linked Lists

**模式标签**：双指针追逐

**状态**：AC非最优

- **难度**：Easy
- **标签**：链表、双指针、哈希表
- **链接**：https://leetcode.cn/problems/intersection-node-lcci/

## 题目描述

找出两个单链表相交的起始节点，不相交返回 None。

## 关键思路

**双指针走对方的路。** pA 走完 A 后切到 B，pB 走完 B 后切到 A。若相交，两者走过的总路程相等，必然在交点相遇；若不相交，同时走到 None。

> 消除长度差：`len(A) + len(B) = len(B) + len(A)`。两个指针交换跑道后走过的总长度相同，天然对齐。O(n+m) 时间，O(1) 空间。

## 代码实现

### 最优解：双指针 O(1) 空间

```python
class Solution:
    def getIntersectionNode(self, headA: ListNode, headB: ListNode) -> Optional[ListNode]:
        pA, pB = headA, headB

        while pA != pB:
            pA = pA.next if pA else headB   # A 走完切到 B
            pB = pB.next if pB else headA   # B 走完切到 A

        return pA   # 要么交点，要么 None
```

### 你的 AC 解法：哈希记录 O(n) 空间

```python
class Solution:
    def getIntersectionNode(self, headA: ListNode, headB: ListNode) -> Optional[ListNode]:
        seen = []
        while headA:
            seen.append(headA)
            headA = headA.next

        # 巧技：先检查 B 的尾节点是否在 A 中，不在则直接返回
        theadB = headB
        while theadB.next:
            theadB = theadB.next
        if theadB not in seen:
            return None

        while headB:
            if headB in seen:
                return headB
            headB = headB.next
        return None
```

### 双指针图解

```
A:  a1 → a2
            ↘
              c1 → c2 → c3
            ↗
B:  b1 → b2 → b3

pA 路径: a1 → a2 → c1 → c2 → c3 → b1 → b2 → b3 → c1
pB 路径: b1 → b2 → b3 → c1 → c2 → c3 → a1 → a2 → c1
                                                  ↑
                                          同时到达交点!

不相交时:
pA: a1 → a2 → None → b1 → b2 → None
pB: b1 → b2 → None → a1 → a2 → None
                            ↑
                      同时到达 None
```

### 为什么交换跑道后必然相遇

```
设 A 独有长度 = a, B 独有长度 = b, 共享部分 = c

pA 走: a + c + b    (走完 A+共享 后切入 B 独有部分)
pB 走: b + c + a    (走完 B+共享 后切入 A 独有部分)

a + c + b = b + c + a  ← 总路程相等
```
