# 94. Binary Tree Inorder Traversal

**模式标签**：中序遍历（递归 / 迭代）

**状态**：AC非最优

- **难度**：Easy
- **标签**：树、栈、递归
- **链接**：https://leetcode.cn/problems/binary-tree-inorder-traversal/

## 题目描述

返回二叉树的中序遍历（左子树 → 根 → 右子树）。

## 关键思路

**递归版：返回值统一为列表，列表拼列表用 extend（或 + 拼接），空树返回 []。** 迭代版：显式用栈模拟递归，节点一路压左，弹出来访问后再转右子树。

> 中序迭代的核心：每次先走到最左，沿途把节点压栈；弹出时访问（此时左子树已处理完），然后转向右子树继续同样的流程。

## 代码实现

### 你的 AC 解法（递归 + extend）

```python
class Solution:
    def inorderTraversal(self, root: Optional[TreeNode]) -> List[int]:
        ans = []
        if root is None:
            return []
        ans.extend(self.inorderTraversal(root.left))
        ans.append(root.val)
        ans.extend(self.inorderTraversal(root.right))
        return ans
```

### 简洁版（递归 + 拼接）

```python
class Solution:
    def inorderTraversal(self, root: Optional[TreeNode]) -> List[int]:
        if root is None:
            return []
        return self.inorderTraversal(root.left) + [root.val] + self.inorderTraversal(root.right)
```

### 迭代版（显式栈，O(1) 空间辅助）

```python
class Solution:
    def inorderTraversal(self, root: Optional[TreeNode]) -> List[int]:
        ans = []
        stack = []
        cur = root

        while cur or stack:
            # 一路压左到底
            while cur:
                stack.append(cur)
                cur = cur.left
            # 弹出访问，转右
            cur = stack.pop()
            ans.append(cur.val)
            cur = cur.right

        return ans
```

### 手动推演：`[1, null, 2, 3]`

```
      1
       \
        2
       /
      3

迭代过程:
  cur=1 → 压1 → cur=null, 弹出1, ans=[1], cur=2
  压2 → cur=3 → 压3 → cur=null
  弹出3, ans=[1,3], cur=null
  弹出2, ans=[1,3,2], cur=null
  栈空 cur 空 → 结束

输出 [1,3,2] ✓
```

## 复杂度分析

| 方法 | 时间 | 空间 |
|------|------|------|
| 递归 | O(n) | O(树高)（递归栈） |
| 迭代 | O(n) | O(树高)（显式栈） |

## 错误记录

### 初始错误代码

```python
if root is None:
    return          # 返回 None，与函数声明 List 类型不符

ans.append(self.inorderTraversal(root.left))   # append 列表 → 嵌套
ans.append(root.val)
ans.append(self.inorderTraversal(root.right))

cleaned = [x for x in ans if x is not None]    # 过滤掩盖问题
return cleaned
```

### 错误分析

| 问题 | 说明 |
|------|------|
| **append 导致嵌套** | `self.inorderTraversal(root.left)` 返回的是列表，`append` 整个装进去产生 `[[2,1], 3]` 结构，应用 `extend` 或 `+` 拼接 |
| **终止条件返回 None** | 函数声明返回 `List[int]`，空树却返回 `None`，类型不一致 |
| **过滤是掩盖不是修复** | `cleaned` 过滤把上述两个错误藏起来了——修好根源后这行成为冗余代码 |

### 教训

| 场景 | 做法 |
|------|------|
| 递归返回值是列表 | 合并子结果用 `extend` / `+`，不用 `append` |
| 空输入 | 返回值类型与正常分支保持一致（空树 → `[]`） |
| 数据出现"不该出现"的值 | 先修根源，不要用过滤/特判掩盖 |
