# 238. Product of Array Except Self

**模式标签**：前缀积 + 后缀积
**状态**：AC非最优

- **难度**：Medium
- **标签**：数组、前缀积
- **链接**：https://leetcode.cn/problems/product-of-array-except-self/

## 题目描述

返回数组 `answer`，其中 `answer[i]` 等于 `nums` 中除 `nums[i]` 之外所有元素的乘积。不能使用除法，O(n) 时间。

## 关键思路

**前缀积 × 后缀积**：`answer[i] = 左边所有元素的积 × 右边所有元素的积`，两趟扫描分别填充。

> 第一趟从左到右：`ans[i]` = 左侧累积积。第二趟从右到左：`ans[i] *= 右侧累积积`。两次遍历，O(n) 时间，O(1) 额外空间（ans 不算额外空间）。

## 代码实现

### 最优解：前缀积 + 后缀积 O(n) / O(1)

```python
class Solution:
    def productExceptSelf(self, nums: List[int]) -> List[int]:
        n = len(nums)
        ans = [1] * n

        # 第一趟：ans[i] = nums[0] * nums[1] * ... * nums[i-1]
        prefix = 1
        for i in range(n):
            ans[i] = prefix
            prefix *= nums[i]

        # 第二趟：ans[i] *= nums[i+1] * ... * nums[n-1]
        suffix = 1
        for i in range(n - 1, -1, -1):
            ans[i] *= suffix
            suffix *= nums[i]

        return ans
```


```
  i=0: ans[0]=1,           prefix=1*1=1

后缀趟（从右到左）:
  i=3: ans[3]*=1,          suffix=1*4=4
  i=2: ans[2]*=4,          suffix=4*3=12

  i=0: ans[0]*=24,         suffix=24*1=24
  → ans = [24, 12, 8, 6]  ✓
```

## 最优解详解

### 核心公式

```
answer[i] = (nums[i] 左边所有元素的乘积) × (nums[i] 右边所有元素的乘积)
          = left_product[i] × right_product[i]
```

### 为什么两趟扫描？

**第一趟（前缀趟）**：从左到右，把"左边的累积积"写入 `ans[i]`。

```python
prefix = 1            # i=0 左边没有元素，积为 1
for i in range(n):
    ans[i] = prefix   # 先把左边积填进去
    prefix *= nums[i] # 再把当前元素乘入 prefix，给下一个位置用
```

每一步 `prefix` 存的是 `nums[0] * ... * nums[i-1]`，恰好就是 `ans[i]` 需要的左侧积。填完后立即把 `nums[i]` 乘入 `prefix`，供下一个 `i` 使用。

**第二趟（后缀趟）**：从右到左，把"右边的累积积"乘到 `ans[i]` 上。

```python
suffix = 1            # i=n-1 右边没有元素，积为 1
for i in range(n - 1, -1, -1):
    ans[i] *= suffix  # 乘上右边积
    suffix *= nums[i] # 把当前元素乘入 suffix，给上一个位置用
```

### 和你的做法对比

```
你的做法（以 i=2 为例）:
  ans[2] = prod([1,2])   ×  prod([4])
         = 左侧积           ×  右侧积
         = O(n) 切片计算    ×  O(n) 切片计算

最优解:
  ans[2] = ans[2]  ×  suffix
         = 左侧积     ×  右侧积
         = O(1) 取值   ×  O(1) 取值

区别: 你的每次重新算，最优解用变量一路累积传递
```

### 为什么空间是 O(1)？

虽然用了一个 `ans` 数组，但题目要求返回的就是一个数组，`ans` 属于输出，不计入额外空间。除此之外只有 `prefix` 和 `suffix` 两个 int 变量。

## 复杂度分析

| 方法 | 时间 | 空间 |
|------|------|------|
| 前缀+后缀 | O(n) | O(1) |
| 切片 prod + 缓存 | O(n²) 最坏 | O(n) |
