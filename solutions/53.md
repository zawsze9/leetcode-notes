# 53. Maximum Subarray

**模式标签**：动态规划 / Kadane 算法
**状态**：思路正确但不能AC

- **难度**：Medium
- **标签**：数组、动态规划、分治
- **链接**：https://leetcode.cn/problems/maximum-subarray/

## 题目描述

找出数组中具有最大和的连续子数组，返回其最大和。

## 关键思路

**每个位置只有两种选择：自己单干，或接在现有子数组后面。**

> `dp[i]` = 以 `nums[i]` 结尾的最大子数组和。递推：`dp[i] = max(nums[i], dp[i-1] + nums[i])`。若 `dp[i-1]` 是负贡献，甩掉重来；若是正贡献，接上更好。由于只依赖上一步，用单变量 `cur` 替代 dp 数组，空间 O(1)。

## 代码实现

```python
class Solution:
    def maxSubArray(self, nums: List[int]) -> int:
        cur = ans = nums[0]
        for num in nums[1:]:
            cur = max(num, cur + num)
            ans = max(ans, cur)
        return ans
```

### 手动推演：`nums = [-2, 1, -3, 4, -1, 2, 1, -5, 4]`

```
 i  num   cur+num  vs  自己单干  →  cur   ans
─── ───   ───────      ──────      ───   ───
 0  -2    (初始)                          -2
 1   1     -2+1=-1  vs    1     →   1      1
 2  -3      1-3=-2  vs   -3     →  -2      1
 3   4     -2+4=2   vs    4     →   4      4
 4  -1      4-1=3   vs   -1     →   3      4
 5   2      3+2=5   vs    2     →   5      5
 6   1      5+1=6   vs    1     →   6      6  ← 最大
 7  -5      6-5=1   vs   -5     →   1      6
 8   4      1+4=5   vs    4     →   5      6
```

**直觉**：前面累积是正贡献就接上，是负贡献就甩掉重新开始。

### 教训

子数组最值问题优先考虑动态规划。前缀和适合"统计等于/满足某条件的子数组个数"，不适合"求最大子数组和"。

## 动态规划速查

### 一句话定义

> 把大问题拆成重叠的小问题，从小到大数据递推答案，避免重复计算。

### 三步法

| 步骤 | 说明 | 例（题 53） |
|------|------|------------|
| ① 定义状态 | `dp[i]` 表示什么？ | `dp[i]` = 以 `nums[i]` 结尾的最大子数组和 |
| ② 递推关系 | `dp[i]` 和 `dp[i-1]` 怎么关联？ | `dp[i] = max(nums[i], dp[i-1] + nums[i])` |
| ③ 初始化 + 顺序 | 初始值？从哪到哪填？ | `dp[0] = nums[0]`，从左到右 |

### 核心要素

**最优子结构**：问题的最优解包含子问题的最优解。
> 例子：`dp[5]` 的最大子数组一定来自 `dp[4]` 的最优子数组 + num[5]，或 num[5] 自己。

**重叠子问题**：子问题被反复用到，需要缓存避免重复。
> 例子：求 `dp[5]` 需要 `dp[4]`，`dp[4]` 需要 `dp[3]` …… 每个中间结果只算一次。

### 两套写法

```python
# 1. 自顶向下（记忆化搜索）：递归 + 缓存
memo = {}
def dp(i):
    if i == 0:
        return nums[0]
    if i in memo:
        return memo[i]
    memo[i] = max(nums[i], dp(i - 1) + nums[i])
    return memo[i]

# 2. 自底向上（递推）：循环填表，更常用
dp = [0] * n
dp[0] = nums[0]
for i in range(1, n):
    dp[i] = max(nums[i], dp[i - 1] + nums[i])
```

### 空间优化信号

若 `dp[i]` 只依赖 `dp[i-1]`（题 53），用单个变量代替整个数组：

```python
cur = nums[0]
for num in nums[1:]:
    cur = max(num, cur + num)
```

### 典型信号：什么时候用 DP？

| 信号 | 例子 |
|------|------|
| 求**最值**（最大/最小/最优） | 最大子数组和、最少硬币 |
| 求**方案数** | 不同路径数、爬楼梯方法数 |
| 问题有明显**重叠子问题** | 斐波那契、背包 |
| 每一步**只依赖前几步** | 爬楼梯、最大子数组 |
