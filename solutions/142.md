# 142. Linked List Cycle II

**模式标签**：快慢指针 + 数学 / 哈希记录

**状态**：AC非最优

- **难度**：Medium
- **标签**：链表、双指针、哈希表
- **链接**：https://leetcode.cn/problems/linked-list-cycle-ii/

## 题目描述

判断链表是否有环，有则返回环的入口节点，无则返回 None。

## 关键思路

**哈希记录法天然找入口：** 第一个重复出现的节点就是环入口（第一次回头碰到自己走过的路）。

**快慢指针法需要两步：** ① 快慢指针相遇（判断有环，环内任意点）；② 相遇后一个指针回 head，两者各走一步，再次相遇处 = 环入口。

> 第二步的依据：相遇时 `a = (n-1)L + c`（a=头到入口，L=环长，c=相遇点到入口），从 head 和相遇点各走一步，必在入口重合。

## 代码实现

### 你的 AC 解法：哈希记录

```python
class Solution:
    def detectCycle(self, head: Optional[ListNode]) -> Optional[ListNode]:
        seen = []
        while head:
            if head in seen:
                return head      # 第一个重复节点 = 环入口
            seen.append(head)
            head = head.next
        return None
```

### 最优解：快慢指针 O(1) 空间

```python
class Solution:
    def detectCycle(self, head: Optional[ListNode]) -> Optional[ListNode]:
        slow = fast = head

        while fast and fast.next:
            slow = slow.next
            fast = fast.next.next
            if slow == fast:          # ① 有环，相遇在环内某点
                fast = head           # ② 一个指针回 head
                while slow != fast:   # 各走一步
                    slow = slow.next
                    fast = fast.next
                return slow           # 再次相遇处 = 环入口

        return None
```

## 复杂度分析

| 方法 | 时间 | 空间 |
|------|------|------|
| 快慢指针 | O(n) | O(1) |
| 哈希记录 | O(n) | O(n) |

## 错误记录

### 过程中暴露的问题

**问题 1：没看懂题目要求返回什么**

> 141 只问"有没有环"（返回 bool），142 要返回**环入口节点**（第一个进入环的节点，如 `1→2→3→4→5→6→3` 中入口是 3），无环返回 None。

**问题 2：试图直接复用 141 的相遇即返回**

```python
if slow == fast:
    return fast   # ✗ 返回的是环内任意点，不是入口
```

| 误区 | 说明 |
|------|------|
| **相遇点 ≠ 环入口** | 相遇位置取决于 head 到入口的距离和环长，在环内随机落点。示例 `1→2→3→4→5→6→3` 中相遇在 5，入口是 3 |
| **缺少"回 head 再走"的第二步** | 必须让一个指针回到 head，两者各走一步，第二次相遇才在入口 |
| **数学推导不理解** | `a = (n-1)L + c`：相遇时快指针多走整圈数，头到入口的距离与相遇点到入口的距离差为整圈，所以从两端各走 a 步必在入口会合 |

**问题 3：对"环入口"概念不清晰**

> 入口是**从 head 出发第一个再次访问到的节点**（第一个重复节点）。哈希记录法因为记录了访问顺序，天然就是它。

### 教训

| 场景 | 正确做法 |
|------|---------|
| 只判断有环 | 快慢指针相遇即 True |
| 还要找入口 | 相遇后一指针回 head，各走一步再相遇 |
| 哈希记录法 | 第一个重复节点就是入口，实现简单但 O(n) 空间 |
