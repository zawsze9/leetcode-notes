# 19. Remove Nth Node From End of List

**模式标签**：哨兵节点 + 双指针 / 数长度定位

**状态**：AC且最优

- **难度**：Medium
- **标签**：链表、双指针
- **链接**：https://leetcode.cn/problems/remove-nth-node-from-end-of-list/

## 题目描述

删除链表的倒数第 n 个节点，返回链表头。

## 关键思路

**dummy 哨兵 + 精确定位前驱。** 倒数第 n 个节点 = 正数第 L-n+1 个节点，其前驱是第 L-n 个节点（dummy 算第 0 个）。数出长度后从 dummy 走 L-n 步即到前驱，`prev.next = prev.next.next` 完成删除。

> dummy 哨兵吸收"删除头节点"特判，正确的步数吸收"删除尾节点"特判。无需接假尾巴、无需删除后清理。

## 代码实现

### 你的 AC 解法：数长度 + 定位

```python
class Solution:
    def removeNthFromEnd(self, head: Optional[ListNode], n: int) -> Optional[ListNode]:
        dummyh = ListNode(val=-1, next=head)
        num = 0
        while head.next:          # 注意：num = L-1 而非 L
            num += 1
            head = head.next

        tmp = dummyh
        i = 0
        while i <= num - n:       # 共走 num-n+1 = L-n 步，停在待删节点的前驱
            tmp = tmp.next
            i += 1
        tmp.next = tmp.next.next

        return dummyh.next
```

### 对照：num 语义直白版（推荐）

```python
class Solution:
    def removeNthFromEnd(self, head: Optional[ListNode], n: int) -> Optional[ListNode]:
        dummy = ListNode(0, head)
        num = 0
        cur = head
        while cur:               # num = L（真实长度）
            num += 1
            cur = cur.next

        tmp = dummy
        for _ in range(num - n): # 走 L-n 步到前驱
            tmp = tmp.next
        tmp.next = tmp.next.next

        return dummy.next
```

### 最优：双指针单遍遍历（无需数长度）

```python
class Solution:
    def removeNthFromEnd(self, head: Optional[ListNode], n: int) -> Optional[ListNode]:
        dummy = ListNode(0, head)
        fast = slow = dummy
        for _ in range(n + 1):   # 快指针先走 n+1 步
            fast = fast.next
        while fast:              # 快慢一起走，快到头时 slow 停在倒数第 n+1 个
            fast = fast.next
            slow = slow.next
        slow.next = slow.next.next
        return dummy.next
```

## 复杂度分析

- 时间复杂度：O(L)
- 空间复杂度：O(1)

## 错误记录

### 第一版：接假尾巴 + 清理循环 → 死循环超时

```python
head.next = dummyt          # 尾部接 -1 哨兵
...
tmp.next = tmp.next.next    # 删除
while tmp.next:             # 清理假尾巴
    if tmp.next.val == -1:
        tmp.next = None     # ← 若 tmp.next 不是 -1，永不满足，死循环!
```

### 错误分析

| 问题 | 说明 |
|------|------|
| **死循环根因** | 清理循环 `while tmp.next:` 在 `tmp.next.val != -1` 时循环体不执行，`tmp.next` 永远非空 → 超时 |
| **假尾巴制造新边界** | 为了删最后一个节点接 -1 哨兵，删完还要摘掉，边界叠边界 |
| **计数错位** | `while head.next` 数出的 num = L-1，按 `num-n` 走会少 1 步，删错节点 |
| **担心"短链表末尾"** | 其实 dummy 哨兵（吸收删头）+ 正确步数（吸收删尾）已覆盖所有边界，不需要假尾巴 |

### 边界验证（曾经担心的场景）

```
L=1, [1], n=1:  num=0, num-n=-1, 循环不走, tmp=dummyh
                tmp.next=1.next=None → 返回 None ✓（删头）

L=3, [1,2,3], n=1: 走 2 步 tmp 停在 2, 2.next=3.next=None ✓（删尾）

n=3:  num-n=-1, tmp=dummyh → dummyh.next=2 ✓（删头）
```

### 教训

| 场景 | 做法 |
|------|------|
| 删除/插入涉及头节点 | dummy 哨兵，返回 dummy.next |
| 删除倒数第 n 个 | 定位到前驱再删（走 L-n 步），而不是直接定位被删节点 |
| 不要用"假值标记"处理链尾 | 假尾巴制造清理循环，必出死循环；用步数计算吸收边界 |
