# 114. Flatten Binary Tree to Linked List

**模式标签**：DFS 遍历骨架（前序收集 + 重建）——#94 家族变式

**母题**：#94 Binary Tree Inorder Traversal（转折点见文末）

**状态**：AC非最优

**完成方式**：纠错后通过

- **难度**：Medium
- **标签**：树、深度优先搜索、链表
- **链接**：https://leetcode.cn/problems/flatten-binary-tree-to-linked-list/

## 题目描述

把二叉树原地展开为"链表"：展开后仍用同样的 `TreeNode`，`right` 指针依次串联，顺序与前序遍历相同，所有 `left` 为 `None`。函数不返回值，原地修改。

示例：

```text
    1
   / \
  2   5          →    1 → 2 → 3 → 4 → 5 → 6（全部走 right 指针）
 / \   \
3   4   6
```

## 关键思路

前序序列就是展开后的链顺序。两条路线：

| 路线 | 做法 | 代价 |
|------|------|------|
| 你的（收集 + 重建） | 前序收集所有值 → 从根逐格重建：填值、`left = None`、"还有下一个"才接新格 | O(n) / O(n)，新建 n−1 个节点 |
| 正宗 1（就地搬移） | 左子树整体搬到右边：原右子树接到"左子树最右节点"后面，`right = 原左`、`left = None` | O(n) / O(1)，零新节点 |
| 正宗 2（反向前序递归） | 按 右→左→根 遍历，`self.prev` 记上一个访问节点，`node.right = prev` 往回搭链 | O(n) / O(H) |

## 代码实现

### 你的 AC 解法（前序收集 + 重建）

```python
class Solution:
    def flatten(self, root: Optional[TreeNode]) -> None:
        pre_order=[]
        def pre(root: Optional[TreeNode]):
            if not root:
                return
            pre_order.append(root.val)
            pre(root.left)
            pre(root.right)
        pre(root)
        for i in range(len(pre_order)):
            root.val=pre_order[i]
            root.left=None
            if not i==len(pre_order)-1:
                root.right=TreeNode()
                root=root.right
```

打磨点：`not i==len(pre_order)-1` 等价于 `i < len(pre_order)-1`，后者不用人脑反转两次。

### 进阶参考 1：就地搬移（O(1) 空间，零新节点）

```python
class Solution:
    def flatten(self, root: Optional[TreeNode]) -> None:
        cur = root
        while cur:
            if cur.left:
                pred = cur.left
                while pred.right:      # 找左子树的最右节点（前序前驱）
                    pred = pred.right
                pred.right = cur.right  # 原右子树挂到前驱后面
                cur.right = cur.left    # 左子树整体搬右
                cur.left = None
            cur = cur.right
```

### 进阶参考 2：反向前序递归（self 挂状态，#98/#230 同家族）

```python
class Solution:
    def flatten(self, root: Optional[TreeNode]) -> None:
        self.prev = None
        def dfs(node):
            if not node:
                return
            dfs(node.right)
            dfs(node.left)
            node.right = self.prev
            node.left = None
            self.prev = node
        dfs(root)
```

访问序列是前序的镜像（右→左→根），从链尾往回头搭：每个节点指向"上一个访问的"。

### 手动推演（就地搬移）

初始：

```text
      1
     / \
    2   5
   / \   \
  3   4   6
```

**第 1 步：cur = 1**（左子树存在）

- 左子树的最右节点：从 2 一路向右 `2 → 4`，4.right 为空，前驱是 **4**
- `4.right = 1.right`：以 5 为根的原右子树挂到 4 的右边
- `1.right = 1.left`、`1.left = None`：左子树整体搬右
- `cur = 1.right = 2`

```text
1
 \
  2      ← 注意：2 的左右孩子没被动过，left=3、right=4 原封不动
 / \
3   4
     \
      5
       \
        6
```

**第 2 步：cur = 2**（左子树存在）

- 左子树最右：3（3.right 为空），前驱是 **3**
- `3.right = 2.right`：**2 的右孩子 4 接到 3 的右边** ← 3→4 的连接在这里发生
- `2.right = 2.left`（即 2.right = 3）、`2.left = None`
- `cur = 2.right = 3`

```text
1 → 2 → 3 → 4 → 5 → 6   （全部走 right 指针，完成）
```

**第 3~6 步：cur = 3、4、5、6**——left 全为 None，直接 `cur = cur.right` 沿右链走完。

关键观察：第 1 步只改了 `4.right`、`1.right`、`1.left` 三个指针，**2 的孩子原封未动**——所以走到 2 时它仍是完整的 `left=3, right=4`，`3.right = 2.right` 才把 4 接进链里。

## 复杂度分析

| 方法 | 时间 | 空间 |
|------|------|------|
| 收集 + 重建（你的） | O(n) | O(n)（收集列表 + n−1 个新节点） |
| 就地搬移 | O(n) | O(1) |
| 反向前序递归 | O(n) | O(H) |

## 错误记录

### 初始错误代码（v1：双幽灵）

```python
for i in range(len(pre_order)):
    root.val=pre_order[i]
    root.left=TreeNode(val=None)   # 幽灵左孩子
    root.right=TreeNode()          # 无条件延伸 → 幽灵尾节点
    root=root.right
```

### 错误分析

| 问题 | 说明 |
|------|------|
| `TreeNode(val=None)` ≠ `None` | 造出一个"值为 None 的真节点"挂在每个节点的左边；判题器看到额外节点，不是空指针 |
| 无条件延伸（收尾多做一步） | 处理完最后一个值后仍新建 left/right，右链尾部多一个 `val=0` 的节点，输出末尾多个 0。与 #102 幽灵空层同族（详见 [收尾多做一步笔记](../notes/收尾多做一步.md)） |
| 新建节点偏离 in-place | 题目意图是重排原节点；重建式多耗 n−1 个节点与 O(n) 空间，方向上退而求其次 |

### 教训

| 场景 | 做法 |
|------|------|
| 清空指针 | 直接赋 `None`，不造"值为 None 的对象" |
| 循环体里创建/延伸结构 | 延伸动作加"还有下一个"守卫（`i < len - 1`），对最后一个元素单独走一遍自查 |
| in-place 题 | 先想"能不能只重排原节点"；收集重建是通过但非本意的路线 |
| 守卫可读性 | `i < len - 1` 优于 `not i == len - 1` |

## Python 概念备忘

**`TreeNode(val=None)` ≠ `None`**：前者是"值为 None 的节点对象"，后者是空指针本身。`node.left = TreeNode(None)` 是挂上一个幽灵节点；`node.left = None` 才是摘掉。与 #94 的"返回类型一致"同一条纪律——空就是空，别造假的空。

## 母题与转折点

**母题**：#94 Binary Tree Inorder Traversal（DFS 遍历骨架家族）

**转折点**：① `append` 从两次递归**之间**挪到**之前**，中序变前序；② 收集后从根重建右链（正宗解则完全不用收集，原地重排）。
