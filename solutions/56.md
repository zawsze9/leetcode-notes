# 56. Merge Intervals

**模式标签**：排序 + 合并
**状态**：AC且最优

- **难度**：Medium
- **标签**：数组、排序
- **链接**：https://leetcode.cn/problems/merge-intervals/

## 题目描述

合并所有重叠的区间，返回不重叠的区间数组。

## 关键思路

**排序 + 贪心合并**：按左端点排序后，重叠条件为 `当前[1] >= 下一个[0]`，合并为 `[当前[0], max(当前[1], 下一个[1])]`。

> 排序保证了只可能相邻区间重叠。用 while 循环原地合并时，合并后 `continue` 不递增 i，让指针停在当前位置继续和新的下一个比较（处理连续合并场景如 `[1,4]→[2,3]→[3,5]`）。

## 代码实现

```python
class Solution:
    def merge(self, intervals: List[List[int]]) -> List[List[int]]:
        intervals = sorted(intervals)
        i = 0
        while i < len(intervals) - 1:
            v = intervals[i]
            if v[1] >= intervals[i + 1][0]:
                intervals[i] = [v[0], max(v[1], intervals[i + 1][1])]
                intervals.pop(i + 1)          # 删除被合并的区间
                continue                      # i 不变，继续和下一个比较
            i += 1
        return intervals
```

### 附加：新建结果列表写法（更直观）

```python
class Solution:
    def merge(self, intervals: List[List[int]]) -> List[List[int]]:
        intervals.sort()
        ans = [intervals[0]]
        for start, end in intervals[1:]:
            if start <= ans[-1][1]:
                ans[-1][1] = max(ans[-1][1], end)
            else:
                ans.append([start, end])
        return ans
```

### 手动推演：`[[1,3],[2,6],[8,10],[15,18]]`

```
排序后: [[1,3],[2,6],[8,10],[15,18]]

i=0: [1,3] 的 3 >= [2,6] 的 2 → 合并为 [1,6], pop掉[2,6], continue
i=0: [1,6] 的 6 < [8,10] 的 8 → 不合并, i=1
i=1: [8,10] 的 10 < [15,18] 的 15 → 不合并, i=2

结果: [[1,6],[8,10],[15,18]]
```

## 复杂度分析

- 时间复杂度：O(n log n)（排序主导）
- 空间复杂度：O(1)（原地合并） / O(n)（新建列表）
