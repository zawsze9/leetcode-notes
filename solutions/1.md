# 1. Two Sum

- **难度**：Easy
- **标签**：数组、哈希表
- **链接**：https://leetcode.cn/problems/two-sum/

## 题目描述

在数组中找到两个数，使它们的和等于 target，返回两个数的下标。每个输入只有一个答案，不能重复使用同一元素。

## 关键思路

查找问题天然适合用哈希表

边查边建 把已扫描的信息"记住"

> 遍历时用哈希表记录每个数的下标，检查 `target - num` 是否已出现过。一趟扫描即可，无需先建完整表再查。

## 代码实现

```python
class Solution:
    def twoSum(self, nums: List[int], target: int) -> List[int]:
        seen = {}  # value -> index
        for i, num in enumerate(nums):
            complement = target - num
            if complement in seen:
                return [seen[complement], i]
            seen[num] = i
        return []
```

## 复杂度分析

- 时间复杂度：O(n)
- 空间复杂度：O(n)
