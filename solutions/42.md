# 42. Trapping Rain Water

**模式标签**：前后缀最大值 / 对撞双指针

- **难度**：Hard
- **标签**：数组、双指针、动态规划、单调栈
- **链接**：https://leetcode.cn/problems/trapping-rain-water/

## 题目描述

给定一个非负整数数组表示柱子高度，计算下雨后能接多少单位雨水。

## 关键思路

**每根柱子能接的水 = min(左侧最高, 右侧最高) - 自身高度**（若为正）。

> 核心问题是如何高效获取每个位置的左右最大值。暴力每位置重新扫描是 O(n²)，通过前缀/后缀数组预处理可降为 O(n)。进一步用双指针从两端收缩，可做到 O(1) 额外空间。

## 代码实现

### 方法一：前后缀最大值（O(n) 时间 + O(n) 空间）

```python
class Solution:
    def trap(self, height: List[int]) -> int:
        n = len(height)
        if n == 0:
            return 0

        # 前缀最大值：l_max[i] = max(height[0..i])
        l_max = [0] * n
        l_max[0] = height[0]
        for i in range(1, n):
            l_max[i] = max(l_max[i - 1], height[i])

        # 后缀最大值：r_max[i] = max(height[i..n-1])
        r_max = [0] * n
        r_max[-1] = height[-1]  # -1 即最后一个索引 n-1
        # range(n-2, -1, -1) => 从倒数第二个走到索引0
        for i in range(n - 2, -1, -1):
            r_max[i] = max(r_max[i + 1], height[i])

        ans = 0
        for i in range(n):
            mhei = min(l_max[i], r_max[i])
            if mhei > height[i]:
                ans += mhei - height[i]

        return ans
```

### 方法二：对撞双指针（O(n) 时间 + O(1) 空间）

```python
class Solution:
    def trap(self, height: List[int]) -> int:
        l, r = 0, len(height) - 1
        l_max, r_max = 0, 0
        ans = 0

        while l < r:
            l_max = max(l_max, height[l])
            r_max = max(r_max, height[r])
            if l_max < r_max:
                ans += l_max - height[l]
                l += 1
            else:
                ans += r_max - height[r]
                r -= 1

        return ans
```

**双指针直觉**：水位由短板决定。`l_max < r_max` 时，位置 `l` 的水位已由 `l_max` 锁定（因为右侧最高至少为 `r_max` >= `l_max`），直接结算并左指针右移；反之同理。

## 复杂度分析

| 方法 | 时间 | 空间 |
|------|------|------|
| 前后缀最大值 | O(n) | O(n) |
| 对撞双指针 | O(n) | O(1) |

## 错误记录

### 初始错误代码

```python
class Solution:
    def trap(self, height: List[int]) -> int:
        ans = 0
        for i, v in enumerate(height):
            lm = max(height[:i+1])
            rm = max(height[i:])
            mhei = min(lm, rm)
            if mhei > v:
                ans += (mhei - v)
        return ans
```

### 错误分析

| 问题 | 说明 |
|------|------|
| **O(n²) 超时** | 对每个位置 i，`max(height[:i+1])` 和 `max(height[i:])` 都会重新扫描，单次 O(n)，整体 O(n²)，在大输入下必然超时 |
| **切片复制开销** | `height[:i+1]` 和 `height[i:]` 每次创建新切片，额外增加内存和时间开销 |
| **思路正确但实现低效** | 核心公式 `min(l_max, r_max) - height[i]` 是对的，应该用前缀/后缀数组预先缓存左右最大值 |

### 教训

当对每个位置都需要求左右区间的某种聚合值（max/min/sum）时，考虑 **前缀/后缀预处理** 将重复扫描改为一次 O(n) 预计算。
