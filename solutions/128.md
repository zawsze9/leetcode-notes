# 128. Longest Consecutive Sequence

**模式标签**：序列起点判定

- **难度**：Medium
- **标签**：哈希表、数组
- **链接**：https://leetcode.cn/problems/longest-consecutive-sequence/

## 题目描述

给定一个未排序的整数数组，找出数字连续的最长序列的长度（不要求序列元素在原数组中连续），要求时间复杂度 O(n)。

## 关键思路

将数组转为集合去重。只从序列起点（x-1 不在集合中）开始向后数，确保每个元素只被访问一次，从而实现 O(n)

> 如果对每个元素都做 while 循环向后找连续+1，最坏会退化为 O(n²)。关键优化：只有当 `x-1` 不在集合中时，才说明 x 是一个连续序列的起点，此时才展开查找。这样内层 while 的总执行次数等于数组中连续序列的总长度，摊还 O(n)。

## 代码实现

```python
class Solution:
    def longestConsecutive(self, nums: List[int]) -> int:
        s = set(nums)
        ans = 0
        for x in s:
            if x - 1 not in s:          # x 是某个连续序列的起点
                cur, length = x, 1
                while cur + 1 in s:     # 往后数连续的数
                    cur += 1
                    length += 1
                ans = max(ans, length)
        return ans
```

## 复杂度分析

- 时间复杂度：O(n)
- 空间复杂度：O(n)
