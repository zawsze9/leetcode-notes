# 41. First Missing Positive

**模式标签**：原地哈希 / 循环交换
**状态**：AC非最优

- **难度**：Hard
- **标签**：数组、哈希表
- **链接**：https://leetcode.cn/problems/first-missing-positive/

## 题目描述

找出数组中缺失的第一个正整数，O(n) 时间，O(1) 空间。

## 关键思路

**原地哈希：把数放到它该在的位置上。** 遍历数组，对于值在 `[1, n]` 内的数字，把它换到索引 `num - 1` 的位置（即 1 放索引 0，2 放索引 1，...）。交换完成后，第一个 `nums[i] != i + 1` 的位置就是答案。

> 排序做是 O(n log n)，而循环交换每个数最多被交换一次，总 O(n)。

## 代码实现

### 最优解：循环交换 O(n) / O(1)

```python
class Solution:
    def firstMissingPositive(self, nums: List[int]) -> int:
        n = len(nums)

        for i in range(n):
            # 把 nums[i] 换到 nums[nums[i]-1] 位置上，直到换对或不需要换
            while 1 <= nums[i] <= n and nums[nums[i] - 1] != nums[i]:
                j = nums[i] - 1
                nums[i], nums[j] = nums[j], nums[i]

        for i in range(n):
            if nums[i] != i + 1:
                return i + 1

        return n + 1
```

### 你的 AC 解法：排序扫描 O(n log n)

```python
class Solution:
    def firstMissingPositive(self, nums: List[int]) -> int:
        nums.sort()
        if 1 in nums:
            i = nums.index(1)
            if i == len(nums) - 1:
                return nums[-1] + 1
            while i < len(nums) - 1:
                if nums[i + 1] - nums[i] > 1:
                    return nums[i] + 1
                i += 1
                if i == len(nums) - 1:
                    return nums[-1] + 1
        else:
            return 1
```

## 手动推演：`nums = [3, 4, -1, 1]`

```
交换规则: 如果 nums[i] 在 [1, n] 内，且该值不在正确位置上，交换

i=0: nums[0]=3 在[1,4]内, 应放到索引2
     和 nums[2]交换 → [-1, 4, 3, 1]
     现在 nums[0]=-1 不在[1,4]内, 跳过

i=1: nums[1]=4 在[1,4]内, 应放到索引3
     和 nums[3]交换 → [-1, 1, 3, 4]
     现在 nums[1]=1 在[1,4]内, 应放到索引0
     和 nums[0]交换 → [1, -1, 3, 4]
     现在 nums[1]=-1 不在[1,4]内, 跳过

i=2: nums[2]=3, 3 在索引2 → 已在正确位置, 跳过
i=3: nums[3]=4, 4 在索引3 → 已在正确位置, 跳过

扫描: nums[1]=-1 ≠ 2 → 返回 2  ✓
```
