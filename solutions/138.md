# 138. Copy List with Random Pointer

**模式标签**：哈希映射两遍法

**状态**：AC非最优

- **难度**：Medium
- **标签**：链表、哈希表
- **链接**：https://leetcode.cn/problems/copy-list-with-random-pointer/

## 题目描述

深拷贝带随机指针的链表。新链表每个节点是旧节点的全新副本，next 和 random 指向关系完全对应。

## 关键思路

**哈希映射两遍法：`{旧节点: 新节点}` 一个 dict 搞定。**

> 核心洞察：random 指向的节点可能还没创建，所以"先全部创建、再统一连线"。第 1 遍遍历旧链创建克隆并建映射，第 2 遍用映射查表设置 next/random。用节点对象本身做键，不需要开两个 dict。

## 代码实现

### 你的 AC 解法

```python
class Solution:
    def copyRandomList(self, head: 'Optional[Node]') -> 'Optional[Node]':
        seen = {}
        if not head:
            return None

        # 第1遍: 创建克隆节点，建映射
        tmp = head
        while tmp:
            seen[tmp] = Node(x=tmp.val)
            tmp = tmp.next

        # 第2遍: 连线
        tmp = head
        while tmp:
            if tmp.next:
                seen[tmp].next = seen[tmp.next]
            else:
                seen[tmp].next = None
            if tmp.random:
                seen[tmp].random = seen[tmp.random]
            else:
                seen[tmp].random = None
            tmp = tmp.next

        return seen[head]
```

### 简化版（用 get 消除 if/else）

```python
class Solution:
    def copyRandomList(self, head: 'Optional[Node]') -> 'Optional[Node]':
        seen = {}
        if not head:
            return None

        tmp = head
        while tmp:
            seen[tmp] = Node(x=tmp.val)
            tmp = tmp.next

        tmp = head
        while tmp:
            seen[tmp].next = seen.get(tmp.next)      # None 时返回 None
            seen[tmp].random = seen.get(tmp.random)
            tmp = tmp.next

        return seen[head]
```

### 进阶：原地复制 O(1) 空间（理解即可）

```
三步:
① 在每个旧节点后插入克隆:  A → A' → B → B' → C → C'
② 设置克隆的 random:   A'.random = A.random.next（A.random 的克隆）
③ 拆开: 奇数位旧链、偶数位克隆链
```

## 复杂度分析

| 方法 | 时间 | 空间 |
|------|------|------|
| 哈希两遍法 | O(n) | O(n) |
| 原地复制 | O(n) | O(1) |

## 错误记录

### defaultdict 初始化报错

```python
from collections import defaultdict
seen = defaultdict(Node)      # ✗ 报错: Node 需要 x 参数
seen = defaultdict(lambda: Node(0))   # ✗ 白造一堆垃圾节点
```

**根因**：defaultdict 的工厂函数必须**无参调用**，而 `Node(x=...)` 必须传参。且本题每个键都显式赋值，**根本不需要 defaultdict**，普通 `{}` 才是正确选择。

### if/else 冗余

```python
if tmp.next:
    seen[tmp].next = seen[tmp.next]
else:
    seen[tmp].next = None
```

`seen[tmp.next]` 在 `tmp.next` 为 None 时会 KeyError（dict 无 None 键），所以写了 if/else。用 `seen.get(tmp.next)` 直接返回 None，无需分支。

### 教训

| 场景 | 做法 |
|------|------|
| 键全部显式赋值 | 普通 dict，不要 defaultdict |
| 需要 None 兜底 | `dict.get(key)` 而非 `dict[key]` |
| 深拷贝含交叉引用（next/random） | 两遍法：先造节点，再连指针 |

### 从"没思路"到 AC

| 阶段 | 想法 |
|------|------|
| 初想 | 想用 node 索引存 head 信息 + 再开一个 dict 存 random —— 两个 dict 太复杂 |
| 关键转折 | 用**节点对象本身做键**，一个 dict 解决所有查找 |
| 卡点 | random 指向的节点还没创建 → 两遍法（先建后连） |
| 踩坑 | defaultdict 初始化报错 → 用普通 dict |
