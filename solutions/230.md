# 230. Kth Smallest Element in a BST

**模式标签**：BST 中序遍历（第 k 小 = 中序第 k 个）

**状态**：AC非最优

**完成方式**：一遍通过

- **难度**：Medium
- **标签**：树、深度优先搜索、二叉搜索树
- **链接**：https://leetcode.cn/problems/kth-smallest-element-in-a-bst/

## 题目描述

给定二叉搜索树的根节点 `root` 和整数 `k`，返回树中第 `k` 小的元素（从 1 开始计数）。

进阶：如果树频繁被修改（插入/删除），且需要频繁查第 k 小，如何优化？（见讨论记录）

## 关键思路

**BST 的中序遍历就是升序序列**（#98 刚验证过中序递增性），所以"第 k 小"就是"中序遍历的第 k 个节点"。

解法阶梯：

| 版本 | 思路 | 代价 |
|------|------|------|
| v1（你的 AC） | 前序收集全部节点值 + `sorted()` 排序后取第 k−1 个 | O(n log n) / O(n) |
| 改进 1 | `append` 挪到两次递归中间 → 中序遍历，收集结果天然有序，删掉 `sorted()` | O(n) / O(n) |
| 最优 | 中序遍历 + 计数器，访问到第 k 个立即停 | O(H + k) / O(H) |

v1 的问题：收集 + 排序对**任意**二叉树都成立，BST 的有序性信息被完全浪费——写"收集再排序"之前先问一句：这份数据是否已经隐含有序？

## 代码实现

### 你的 AC 解法（前序收集 + 排序）

```python
class Solution:
    def kthSmallest(self, root: Optional[TreeNode], k: int) -> int:
        ans=[]
        def dfs(root2: Optional[TreeNode]):
            if not root2:
                return None
            ans.append(root2.val)
            dfs(root2.left)
            dfs(root2.right)
        dfs(root2=root)
        ans=sorted(ans)
        return ans[k-1]
```

三个小瑕疵（不影响正确性）：`return None` 没人接（结果靠闭包共享的 `ans` 传递，返回值无用）；`dfs(root2=root)` 关键字参数风格（见 #98 备忘）；如上所述浪费 BST 性质。

### 改进 1：中序收集（只挪一行）

```python
def dfs(node):
    if not node:
        return
    dfs(node.left)
    ans.append(node.val)   # 左、自己、右 → 中序
    dfs(node.right)
```

`append` 的位置决定遍历顺序：前序=根左右、中序=左根右、后序=左右根。中序收集后 `ans` 天然升序，`sorted()` 那行直接删。

### 最优参考：中序 + 计数早停

```python
class Solution:
    def kthSmallest(self, root: Optional[TreeNode], k: int) -> int:
        self.k = k
        self.ans = None

        def inorder(node):
            if not node or self.ans is not None:
                return
            inorder(node.left)
            self.k -= 1
            if self.k == 0:
                self.ans = node.val
                return
            inorder(node.right)

        inorder(root)
        return self.ans
```

`self.ans is not None` 让"找到后"所有挂起的递归帧全线短路，后面的节点不再访问。状态挂 `self`（#543 的 `self.diameter` 同款），也可用闭包变量 + `nonlocal`。

### 手动推演

```text
        5
       / \
      3   6        k = 3
     / \
    2   4
    /
   1
```

| 中序访问 | 节点 | 序号 | 剩余 k | 动作 |
|---------|------|------|--------|------|
| 1 | 1 | 1 | 2 | 继续 |
| 2 | 2 | 2 | 1 | 继续 |
| 3 | 3 | 3 | **0** | **ans = 3，停**（4、5、6 不再访问） |

对比 v1：全部 6 个节点都要访问还要排序；早停版只走 3 步。

## 复杂度分析

| 方法 | 时间 | 空间 |
|------|------|------|
| v1 前序收集 + 排序 | O(n log n) | O(n) |
| 中序全量收集 | O(n) | O(n) |
| 中序 + 计数早停 | O(H + k) | O(H) |

早停版先沿最左链走到最小节点（H 层），再走 k−1 步，栈深 O(H)。

## 错误记录

### 自抓 bug（提交前自己发现并修正）

嵌套函数 `dfs` 的参数表里写了 `self`——嵌套函数不是类方法，没有 `self`。自己发现后改掉了，一次通过。

### 解法复盘（AC 后发现的问题）

| 问题 | 说明 |
|------|------|
| 前序收集 + `sorted()`（核心） | 未用 BST 中序有序性质；收集+排序是"通用二叉树"解法 |
| 全量遍历 | 只需第 k 个，无需访问全部 n 个节点 |
| `return None` 无人接 | dfs 靠共享列表传结果，返回值形同虚设 |
| `dfs(root2=root)` | 关键字参数与入口的位置参数风格混用（#98 备忘） |

### 教训

| 场景 | 做法 |
|------|------|
| BST 求第 k 小 / 第 k 大 | 中序遍历第 k 个 + 计数早停，O(H+k) |
| 想写"收集 + 排序"前 | 先问数据结构是否已隐含有序（BST 中序、堆顶……） |
| 定义嵌套函数 | 参数表没有 `self`；外层变量走闭包共享 |
| 控制遍历顺序 | `append` 相对递归的位置：前=根左右、中=左根右、后=左右根 |

## Python 概念备忘

**嵌套函数没有 `self`**：`self` 只是外层方法的普通参数，嵌套函数是定义在方法体内部的普通函数。若参数表误写 `self`，调用 `dfs(root2=root)` 时 `self` 形参无人传 → `TypeError: missing 1 required positional argument: 'self'`。嵌套函数要用外层状态（如 `ans`），直接闭包读取即可，这是它相对辅助类方法的最大便利。
