# 74. Search a 2D Matrix

**模式标签**：二分查找（lower bound / 插入点）+ 变式：二维拍平坐标映射

**母题**：#35 Search Insert Position（二分骨架逐行同构，转折点 = 坐标映射）

**状态**：AC且最优（纠错后通过）

**完成方式**：纠错后通过

- **难度**：Medium
- **标签**：数组、矩阵、二分查找
- **链接**：https://leetcode.cn/problems/search-a-2d-matrix/

## 题目描述

给定 m×n 矩阵，满足两条性质：

1. 每行整数**升序**排列
2. 每行第一个整数 **大于** 上一行最后一个整数

判断 `target` 是否在矩阵中，要求 **O(log(m·n))** 时间。

示例：`[[1,3,5,7],[10,11,16,20],[23,30,34,60]]`，target=3 → true；target=13 → false。

## 关键思路

⭐ 结构洞察：性质 2（行首 > 上行尾）⟹ **按行拼接后是一条长度 m·n 的严格有序一维数组** ⟹ 整个矩阵等价于一个可全局二分的一维数组。

于是整个算法 = 母题 #35 的二分骨架逐行同构，唯一转折点是**取值时换算坐标**：

```text
idx = row × 列数 + col   ⟺   row = idx // 列数,  col = idx % 列数
```

⭐ **除数是列数**（每行的宽度 / 步长），不是行数——商是"第几行"、余数是"行内第几列"，都相对行内而言。方阵里 `len(matrix)==len(matrix[0])` 会蒙对，非方阵必挂（v3 死因）。

**与 #240 的结构对照**（同是"二维找数"，不同族）：

| 性质 | #74 | #240 |
|------|-----|------|
| 行内递增 | ✓ | ✓ |
| 列内递增 | ✓ | ✓ |
| **行首 > 上一行尾（可拍平）** | ✓ | ✗ |
| 达标解法 | 拍平全局二分 O(log mn) | 右上角排除法 O(m+n) |

动笔前先查"能否拍平"：行首是否 > 上行尾？是 → 二分；否 → 排除法。

## 代码实现

### 你的 AC 解法（拍平二分）

```python
class Solution:
    def searchMatrix(self, matrix: list[list[int]], target: int) -> bool:
        lo = 0
        hi = len(matrix) * len(matrix[0]) - 1
        ans = False
        n = len(matrix[0])                      # ⭐ 除数 = 列数，循环前存好
        while lo <= hi:
            mid = (lo + hi) // 2
            if target > matrix[mid // n][mid % n]:
                lo = mid + 1
            elif target < matrix[mid // n][mid % n]:
                hi = mid - 1
            elif target == matrix[mid // n][mid % n]:
                return True
        return ans
```

可打磨的小点（不影响正确性）：末位 `elif target==...` 可写 `else: return True`；`ans` 变量冗余，结尾直接 `return False`。

### 备选达标形态：两段二分

首列二分找"最后一个行首 ≤ target 的行"（log m），行内二分（log n）。由恒等式 `log(m·n) = log m + log n`，总复杂度同样达标。

### 版本演进对照（本题撞了三道门）

| 版本 | 复杂度 | 结局 |
|------|--------|------|
| v1 阶梯走格（贪心下/右移动） | O(m+n) | ✗ 复杂度门禁静态拦截（且边界 peek 会越界） |
| （更早）首列扫 + 行内右扫 | O(m+n) | ✗ 同拦——被禁的是**线性扫描的级别**，不是"扫列"这个动作 |
| v3 拍平二分，除数误用行数 | O(log mn) ✓ | ✗ WA + IndexError 双死法 |
| v4 除数改列数 | O(log mn) | ✓ AC |

### 手动推演

**映射对照**（3×4 矩阵，行数 3、列数 4）：

| 一维 mid | 正确 (mid//4, mid%4) | 除数错用行数 (mid//3, mid%3) | 判定 |
|---------|---------------------|------------------------------|------|
| 0 | (0,0)=1 | (0,0)=1 | ✓ 蒙对 |
| 5 | **(1,1)**=11 | (1,2)=16 | ✗ 串位 |
| 11 | (2,3)=60 | **(3,2)** | 💥 第 3 行不存在 |

**target=7 收缩（AC 版）**：mid=5→(1,1)=11，7<11→hi=4；mid=2→(0,2)=5，7>5→lo=3；mid=3→(0,3)=7 命中 → True（v3 在此返 False）。

**target=60 收缩**：mid=5→11<60→lo=6；mid=8→(2,0)=23<60→lo=9；mid=10→(2,2)=34<60→lo=11；mid=11→(2,3)=60 命中 → True（v3 在 mid=10 处 `matrix[3][2]` 越界崩）。

## 复杂度分析

| 方法 | 时间 | 空间 |
|------|------|------|
| 拍平二分 | O(log(m·n)) | O(1) |
| 两段二分 | O(log m + log n) = O(log(m·n)) | O(1) |
| 阶梯走格（对照） | O(m+n) | O(1) |

100×100 矩阵：二分约 13 步，线性扫约 200 步。

## 错误记录

### 初始错误代码（v1：阶梯走格）

```python
while 1:
    if matrix[m][n]==target:
        ans=True; break
    elif matrix[m][n]>target:
        break
    elif matrix[m+1][n]<=target:          # 边界处越界
        m=m+1
    elif matrix[m+1][n]>target and matrix[m][n+1]<=target:
        n+=1
    if m==len(matrix) and n==len(matrix[0]):   # 守卫：三重死代码
        break
    ...
```

### 错误分析

| 版本 | 问题 | 说明 |
|------|------|------|
| v1 | O(m+n) 违反进阶要求 | 题目要求的 O(log(m·n)) 是**硬门禁**（静态评审直接拦），不是"建议" |
| v1 | 先访问后守卫 | `matrix[m+1][n]` 在最后一行直接越界；守卫写在访问之后，永远轮不到 |
| v1 | 守卫条件本身死 | ① 合法最大下标是 `len-1` 不是 `len`；② `and` 要求行列同时到头（不可能同时发生）；③ 就算到了也在访问之后 |
| 旧版 | 首列扫 + 行内扫 O(m+n) | 同样被拦——线性扫描换方向不换级别 |
| v3 | ⭐ 映射除数用 `len(matrix)`（行数） | 步长应为**列数**。非方阵两种死法：串位访问错误元素 → WA（target=7 返 False）；行下标跑到 `m` → IndexError（target=60） |
| v3 | 方阵陷阱 | `len(matrix)==len(matrix[0])` 时映射错误不暴露，小方阵测试可能漏网 |

### 教训

| 场景 | 做法 |
|------|------|
| 二维拍平二分 | 除数 = 列数；循环前 `n = len(matrix[0])` 存变量（省掉每轮 6 次 len 求值） |
| 题目给的复杂度要求 | 硬门禁——动笔前先看进阶要求选骨架，O(m+n) 写得再对也过不了 |
| 选骨架前查结构 | "行首 > 上行尾？"是 → 拍平二分（#74）；否 → 排除法（#240） |
| 维度敏感型 bug | 方阵测试测不出来，用非方阵（如 3×4）推演映射表 |

## Python 概念备忘

**`//` 与 `%` 的互逆分解**：`idx = (idx // n) * n + idx % n`——商是"第几个块"、余数是"块内偏移"，n 是块大小。拍平映射、进制转换、循环分组全靠这一对。

**除数即步长**：想"跳到下一行要跨几个元素"，答案就是除数。跨一整行 = 跨列数个元素，所以除数是列数不是行数。

## 讨论记录

- v1 阶梯走格：贪心逻辑本身对 #74 成立（利用行首 > 上行尾），但 O(m+n) 触发复杂度门禁 + 边界 peek 越界，双重不可救。
- 旧版"首列扫 + 行内对比"同样被拦 → 澄清：被禁的是线性扫描的复杂度级别，"列上做二分"完全合法（两段二分前半场）。
- v3 拍平二分一次过复杂度门禁，但除数误用行数 → WA（target=7）+ IndexError（target=60）双死法；指出除数 = 列数。
- v4 AC。判定 AC且最优（纠错后通过）。
- 母子题：**#74 是 #35 的子题**（复习索引中 #35 首次以母题身份进表），转折点 = 二维坐标映射、除数是列数；与 #240 非母子（排除法族），题解放结构对照表防混淆。
