# 101. Symmetric Tree

**模式标签**：递归镜像比较

**状态**：AC且最优

**完成方式**：纠错后通过

- **难度**：Easy
- **标签**：树、递归、深度优先搜索
- **链接**：https://leetcode.cn/problems/symmetric-tree/

## 题目描述

判断一棵二叉树是否以根节点为中心对称。

对称的含义不是分别判断左右子树自身是否对称，而是判断左子树和右子树是否互为镜像：

- 左节点的值等于右节点的值
- 左节点的左子树对应右节点的右子树
- 左节点的右子树对应右节点的左子树

## 关键思路

定义辅助函数 `isMirror(left, right)`，专门判断两个节点是否互为镜像。

递归边界：

1. 两个节点都为空：对称，返回 `True`
2. 只有一个节点为空：不对称，返回 `False`
3. 两个节点值不同：不对称，返回 `False`

递归关系：

```text
isMirror(left, right)
    = isMirror(left.left, right.right)
      and isMirror(left.right, right.left)
```

入口是比较 `root.left` 和 `root.right`。

## 代码实现

### 你的 AC 解法

```python
class Solution:
    def isSymmetric(self, root: Optional[TreeNode]) -> bool:
        def isMirror(left: Optional[TreeNode], right: Optional[TreeNode]):
            if not left and not right:
                return True
            elif (left and not right) or (right and not left):
                return False
            elif left.val != right.val:
                return False
            return isMirror(left.left, right.right) and isMirror(right.left, left.right)

        return isMirror(left=root.left, right=root.right)
```

### 更健壮的写法

题目测试约束下根节点不为空，因此你的代码可以通过；如果希望兼容空树输入，可以在入口处先处理 `root is None`：

```python
class Solution:
    def isSymmetric(self, root: Optional[TreeNode]) -> bool:
        if root is None:
            return True

        def isMirror(left: Optional[TreeNode], right: Optional[TreeNode]) -> bool:
            if left is None or right is None:
                return left is right
            if left.val != right.val:
                return False
            return isMirror(left.left, right.right) and isMirror(left.right, right.left)

        return isMirror(root.left, root.right)
```

### 手动推演

以 `[1,2,2,3,4,4,3]` 为例：

```text
        1
       / \
      2   2
     / \ / \
    3  4 4  3
```

```text
isMirror(2, 2)
├── isMirror(3, 3)  → True
└── isMirror(4, 4)  → True
结果：True
```

如果某一层出现 `left.val != right.val`，或一侧为空另一侧不为空，递归会立即返回 `False`。

## 复杂度分析

| 方法 | 时间 | 空间 |
|------|------|------|
| 递归镜像比较 | O(n) | O(h) |

其中 `n` 是节点数，`h` 是树高。递归过程中每个节点最多访问一次，额外空间来自递归栈。

## 错误记录

### 初始错误代码的主要问题

| 问题 | 说明 |
|------|------|
| 只检查固定两层 | 更深层出现不对称时无法发现 |
| 强制要求部分孙节点存在 | `[1,2,2]` 等合法对称树会被误判 |
| 镜像位置配对错误 | 应比较 `left.left` 与 `right.right`，以及 `left.right` 与 `right.left` |
| 递归调用不可达 | 前面的分支已经全部 `return` |
| 没有处理节点值和空节点组合 | 无法完整表达对称条件 |

### 修正过程

| 阶段 | 修正内容 |
|------|----------|
| 第一步 | 用局部辅助函数 `isMirror` 比较左右两棵子树 |
| 第二步 | 增加两个节点同时为空、只有一个为空的边界判断 |
| 第三步 | 增加节点值比较 |
| 第四步 | 按镜像位置递归：左左对右右、左右对右左 |
| 第五步 | 返回辅助函数的最终结果 |

### 教训

| 场景 | 做法 |
|------|------|
| 树的对称判断 | 比较两个节点对，而不是分别判断两棵子树 |
| 递归树问题 | 先明确当前两个参数之间的关系，再设计子问题 |
| 镜像结构 | 左子树的左方向对应右子树的右方向，左右方向交叉对应 |
