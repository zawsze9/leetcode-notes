# 73. Set Matrix Zeroes

**模式标签**：原地标记
**状态**：思路正确但不能AC

- **难度**：Medium
- **标签**：数组、矩阵、原地算法
- **链接**：https://leetcode.cn/problems/set-matrix-zeroes/

## 题目描述

若矩阵中某元素为 0，则将其所在行和列全部置为 0。必须在原地上修改，不使用额外空间。

## 关键思路

**用第一行第一列本身做标记数组。** `matrix[i][0] = 0` 表示第 i 行需全置零，`matrix[0][j] = 0` 表示第 j 列需全置零。第一行和第一列是否有 0 用两个布尔变量单独记录。

> 不能用 `None` 等特殊标记值，因为题目要求矩阵元素为 int。但矩阵已有的值本身就是合法的"记号"。第一行第一列既参与标记又参与最终置零，所以需要先记下它们原始是否含 0。

## 代码实现

```python
class Solution:
    def setZeroes(self, matrix: List[List[int]]) -> None:
        m, n = len(matrix), len(matrix[0])

        # 1. 先用两个 flag 记录第一行和第一列是否含 0
        row0_has_zero = any(matrix[0][j] == 0 for j in range(n))
        col0_has_zero = any(matrix[i][0] == 0 for i in range(m))

        # 2. 用第一行和第一列做标记
        for i in range(1, m):
            for j in range(1, n):
                if matrix[i][j] == 0:
                    matrix[i][0] = 0    # 标记第 i 行
                    matrix[0][j] = 0    # 标记第 j 列

        # 3. 根据标记置零（跳过第一行第一列）
        for i in range(1, m):
            for j in range(1, n):
                if matrix[i][0] == 0 or matrix[0][j] == 0:
                    matrix[i][j] = 0

        # 4. 处理第一行
        if row0_has_zero:
            for j in range(n):
                matrix[0][j] = 0

        # 5. 处理第一列
        if col0_has_zero:
            for i in range(m):
                matrix[i][0] = 0
```

### 为什么第一行第一列要分开处理

```
如果 matrix[0][1] 本来是 0:
  后面标记时发现 matrix[0][1]==0，会误以为"第1列需要置零"
  但 matrix[0][1] 可能就是原始数据中的 0，不是标记

  解决办法: 先记下 row0_has_zero 和 col0_has_zero
           标记阶段只写不读、置零阶段只读不写
           最后用 flag 单独处理第一行和第一列
```

### 手动推演

```
原始:
┌              ┐
│ 1   1   1   1 │
│ 1   0   1   1 │  ← matrix[1][1] = 0
│ 1   1   1   1 │
└              ┘

步骤1: row0_has_zero = False, col0_has_zero = False

步骤2: 遍历内部(1..m-1, 1..n-1)，用第一行第一列做标记
  i=1,j=1 → matrix[1][1]=0:
    matrix[1][0] = 0    标记第 1 行
    matrix[0][1] = 0    标记第 1 列

  标记后:
  ┌              ┐
  │ 1   0   1   1 │  ← matrix[0][1]=0 标记第 1 列
  │ 0   0   1   1 │  ← matrix[1][0]=0 标记第 1 行
  │ 1   1   1   1 │
  └              ┘

步骤3: 根据标记置零
  遍历 matrix[i][0]==0 → 第 1 行全置零
  遍历 matrix[0][j]==0 → 第 1 列全置零

  最终:
  ┌              ┐
  │ 1   0   1   1 │
  │ 0   0   0   0 │
  │ 1   0   1   1 │
  └              ┘
```

## 复杂度分析

- 时间复杂度：O(m × n)
- 空间复杂度：O(1)（两个布尔变量，其余全用矩阵自身）

## 错误记录

### 错误思路：用 None 做标记

```python
# 遇到 0 就把整行整列标记为 None，最后统一替换为 0
matrix[mm2][inn] = None
# 问题：改变了元素类型 (int→None)，平台不允许
```

### 错误分析

| 问题 | 说明 |
|------|------|
| **`None` 改变了数据类型** | 题目期望 `List[List[int]]`，插入 `None` 后不再是合法 int 矩阵 |
| **遇 0 就遍历整行整列** | 多个 0 在同行列时会重复遍历，最坏 O(mn×(m+n)) |
| **标记值不在矩阵内** | 真正需要的是"用什么信息标记"，最优解用第一行第一列的值作为标记 |

### 教训

**原地标记类问题**，如果不能用特殊值（因为没有预留"，找不到合适的 sentinel），就把现有数据结构的一部分复用为标记存储。矩阵问题优先考虑第一行/第一列充当标记数组。
