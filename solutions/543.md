# 543. Diameter of Binary Tree

**模式标签**：后序递归（树高 + 全局最优）

**状态**：AC且最优

**完成方式**：纠错后通过

- **难度**：Easy
- **标签**：树、递归、深度优先搜索
- **链接**：https://leetcode.cn/problems/diameter-of-binary-tree/

## 题目描述

求二叉树的直径。直径是树中任意两个节点之间最长路径的边数，路径不一定经过根节点。

## 关键思路

定义递归函数 `dfs(node)`：返回当前节点向下延伸的最大深度，使用“节点数”计数。

- 空节点深度为 `0`
- 当前节点的左、右最大深度分别为 `left_depth` 和 `right_depth`
- 经过当前节点的路径长度为 `left_depth + right_depth`
- 返回给父节点的深度为 `1 + max(left_depth, right_depth)`

直径不一定经过根节点，因此每个节点都要计算一次“经过当前节点的路径长度”，并用一个全局变量保存最大值。

这里要区分两个返回/保存的结果：

| 信息 | 用途 |
|------|------|
| `1 + max(left_depth, right_depth)` | 返回给父节点，帮助父节点计算路径 |
| `left_depth + right_depth` | 更新当前节点处的最大直径 |

## 代码实现

### 你的 AC 解法

```python
class Solution:
    def diameterOfBinaryTree(self, root: Optional[TreeNode]) -> int:
        self.diameter = 0

        def dfs(node: Optional[TreeNode]) -> int:
            if not node:
                return 0

            left_depth = dfs(node.left)
            right_depth = dfs(node.right)

            self.diameter = max(self.diameter, left_depth + right_depth)

            return max(left_depth, right_depth) + 1

        dfs(root)
        return self.diameter
```

### 另一种状态保存方式：`nonlocal`

`dfs` 是外层方法中的局部函数，所以不需要 `self.dfs`。如果不想把直径保存为实例属性，也可以在外层使用局部变量，并在嵌套函数中通过 `nonlocal` 修改它：

```python
diameter = 0

def dfs(node):
    nonlocal diameter
    ...
```

你的写法使用 `self.diameter` 同样正确，并且在每次调用 `diameterOfBinaryTree` 时重新初始化了结果。

### 手动推演

```text
      1
     / \
    2   3
   / \
  4   5
```

后序计算：

```text
节点 2：左深度 = 1，右深度 = 1
       经过节点 2 的路径 = 1 + 1 = 2
       返回深度 = 1 + max(1, 1) = 2

节点 3：返回深度 = 1

节点 1：左深度 = 2，右深度 = 1
       经过节点 1 的路径 = 2 + 1 = 3
```

因此最长路径是 `4 → 2 → 1 → 3`，直径为 `3` 条边。

## 复杂度分析

| 方法 | 时间 | 空间 |
|------|------|------|
| 后序递归 | O(n) | O(h) |

每个节点只访问一次，额外空间来自递归栈；`h` 为树高。

## 错误记录

### 卡点

这题的难点不是递归遍历本身，而是区分“递归返回值”和“最终答案”：递归需要返回树高，但题目要求的是全树最大直径。

### 错误分析

| 问题 | 说明 |
|------|------|
| 只从根节点计算路径 | 最长路径可能完全位于某个子树内部 |
| 递归函数直接返回直径 | 父节点需要的是当前节点向下的最大深度，而不是子树直径 |
| 忽略路径经过当前节点的情况 | 当前节点的候选直径应为左深度加右深度 |

### 教训

| 场景 | 做法 |
|------|------|
| 递归函数与题目答案不同 | 先明确函数返回值服务于谁，这里返回给父节点的是深度 |
| 最优值可能出现在任意子树 | 每个节点都更新全局答案，不能只在根节点判断 |
| 局部递归函数保存共享结果 | 可以使用外层实例属性 `self.diameter`，也可以使用 `nonlocal` |

## 讨论记录

- 初始卡点是难以直接想出递归关系。
- 通过拆分为“向下最大深度”和“经过当前节点的路径长度”，确定了后序递归结构。
- 最终代码通过 LeetCode 测试，状态记为“AC且最优”，完成方式为“纠错后通过”。
