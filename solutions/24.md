# 24. Swap Nodes in Pairs

**模式标签**：哨兵节点 + 成对重连

**状态**：AC且最优

- **难度**：Medium
- **标签**：链表、递归
- **链接**：https://leetcode.cn/problems/swap-nodes-in-pairs/

## 题目描述

两两交换链表中的相邻节点（只交换节点，不交换值），奇数个时最后一个节点保持不动。

## 关键思路

**prev 哨兵 + 每对三连重连。** `prev` 是"上一对尾巴"，每轮处理一对：`a`（第一个）、`b`（第二个），依次重连 `a.next = b.next`（a 指向下一对起点）、`b.next = a`（b 指向 a）、`prev.next = b`（前驱指向 b），然后 `prev = a` 前移。

> 用哨兵节点代替"手动记录新头"，循环条件 `prev.next and prev.next.next` 天然吸收"奇数尾巴不换"的边界。

## 代码实现

### 最优解：哨兵写法

```python
class Solution:
    def swapPairs(self, head: Optional[ListNode]) -> Optional[ListNode]:
        dummy = ListNode(0, head)
        prev = dummy                 # 哨兵/前驱

        while prev.next and prev.next.next:
            a = prev.next            # 第一个节点
            b = a.next               # 第二个节点

            a.next = b.next          # ① a 指向下一对起点
            b.next = a               # ② b 指向 a（交换）
            prev.next = b            # ③ 前驱指向 b
            prev = a                 # ④ 前驱前移为 a

        return dummy.next
```

### 你的 AC 解法（等价，可读性差）

```python
class Solution:
    def swapPairs(self, head: Optional[ListNode]) -> Optional[ListNode]:
        ans = head
        if head and head.next:
            ans = head.next          # 手动特判新头
        ttail = head
        while head and head.next:
            tmp = head.next.next
            ttail.next = head.next
            head.next.next = head
            head.next = tmp
            ttail = head
            if tmp is not None:      # 冗余条件
                head = tmp
        return ans
```

### 手动推演：`[1,2,3,4]`

```
dummy → 1 → 2 → 3 → 4

第1对: prev=dummy, a=1, b=2
  a.next=b.next → 1→3
  b.next=a      → 2→1
  prev.next=b   → dummy→2
  prev=a(1)
  → dummy → 2 → 1 → 3 → 4

第2对: prev=1, a=3, b=4
  a.next=b.next → 3→None
  b.next=a      → 4→3
  prev.next=b   → 1→4
  prev=3
  → dummy → 2 → 1 → 4 → 3

返回 dummy.next = 2 → 1 → 4 → 3 ✓
```

### 奇数边界：`[1,2,3]`

```
第1对交换后: 2 → 1 → 3
prev=1, prev.next=3, prev.next.next=None → 循环退出
3 保持不动 ✓
```

## 改进记录

### 你代码中的三个可优化点

| 问题 | 说明 | 修正 |
|------|------|------|
| **冗余条件** | `if tmp is not None: head = tmp`，tmp 为 None 时 `head=tmp` 后循环条件自然为假，if 是多余的 | 直接 `head = tmp` |
| **头特判痕迹** | `ans = head; if head and head.next: ans = head.next` 是"手动找新头" | 用 dummy 哨兵，`return dummy.next` 统一 |
| **命名混乱** | `ttail` 前缀语义不明（实际是前驱）、`tmp` 含义与本仓库其他题冲突 | 命名 `prev/a/b`，角色即名字 |

### 教训

| 场景 | 做法 |
|------|------|
| 链表头会变化（交换/反转/删除） | 一律 dummy 哨兵，头交给 dummy.next |
| 多步重连 | 先取出要操作的节点命名（a、b），再重连，别用 `head.next.next` 连写 |
| 边界条件 | 写进循环条件（`prev.next and prev.next.next`），而不是循环内 if 判断 |
