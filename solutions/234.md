# 234. Palindrome Linked List

**模式标签**：快慢指针 + 链表反转

**状态**：AC非最优

- **难度**：Easy
- **标签**：链表、双指针、递归
- **链接**：https://leetcode.cn/problems/palindrome-linked-list/

## 题目描述

判断单链表是否为回文链表，O(n) 时间，O(1) 空间。

## 关键思路

**快慢指针找中点 + 反转后半段 + 比较。** 快指针每次两步、慢指针每次一步，快指针到尾部时慢指针正好在中点。反转后半段链表后，从两端向中间逐节点比较。

> 存放在数组里是 O(n) 空间，反转后半段只用几个指针，O(1) 空间。

## 代码实现

### 最优解：反转后半段 O(1) 空间

```python
class Solution:
    def isPalindrome(self, head: Optional[ListNode]) -> bool:
        # 1. 快慢指针找中点
        slow = fast = head
        while fast and fast.next:
            slow = slow.next
            fast = fast.next.next

        # 2. 反转后半段
        prev = None
        while slow:
            nxt = slow.next
            slow.next = prev
            prev = slow
            slow = nxt

        # 3. 两端比较
        left, right = head, prev
        while right:   # 后半段更短或等长
            if left.val != right.val:
                return False
            left = left.next
            right = right.next

        return True
```

### 你的 AC 解法：转数组比较 O(n) 空间

```python
class Solution:
    def isPalindrome(self, head: Optional[ListNode]) -> bool:
        chain = []
        while head:
            chain.append(head.val)
            head = head.next
        if chain == list(reversed(chain)):
            return True
        else:
            return False
```

### 手动推演：`1 → 2 → 2 → 1`

```
步骤1 快慢找中点:
  slow=1 fast=1 → slow=2 fast=2 → slow=2 fast=None
  slow 停在第二个 2 (后半段起点)

  前半段: 1 → 2
  后半段: 2 → 1

步骤2 反转后半段:
  2 → 1  反转 →  1 → 2

步骤3 比较:
  left: 1 → 2 → ...
  right: 1 → 2 → ...
  逐节点 1==1, 2==2 → True
```

### 奇偶长度处理

```
奇数: 1 → 2 → 3 → 2 → 1
  慢指针停在 3, 后半段反转: 3 → 2 → 1 反转 → 1 → 2 → 3
  left 从 1 开始, right 从 1 开始
  比较: 1=1, 2=2, left 走到 3(right 已到 None 停) → True
  
  注意: 后半段比前半段多一个节点(中点)，while right 只用后半段长度控制，多出的不理。
```
