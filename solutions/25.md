# 25. Reverse Nodes in k-Group

**模式标签**：探测 + 反转变体 + 锚点连接

**状态**：无思路（在大量帮助下实现）

- **难度**：Hard
- **标签**：链表、递归
- **链接**：https://leetcode.cn/problems/reverse-nodes-in-k-group/

## 题目描述

链表中每 k 个节点一组反转，不足 k 个的保持原样，返回新头。

## 关键思路

**三个环节：① 探测是否够 k 个；② 组内反转（反转一段并接回）；③ 锚点连接下一组。**

> 核心技巧是"反转一段并接回"变体：反转前把 `prev` 初始化为该段后的 `group_next`，反转结束后旧段头自动指向下一段，省掉一次连接。`dummy` 哨兵作为第一组的锚点，吸收头节点特判。

## 代码实现

```python
class Solution:
    def reverseKGroup(self, head: Optional[ListNode], k: int) -> Optional[ListNode]:
        dummy = ListNode(0, head)
        group_prev = dummy                    # 当前组的前一个节点（锚点）

        while True:
            # ① 探测：检查还剩几个节点（不够 k 个直接返回）
            kth = group_prev
            for _ in range(k):
                kth = kth.next
                if not kth:
                    return dummy.next
            group_next = kth.next             # 组的下一段起点

            # ② 组内反转：prev 从 group_next 开始，反转后组尾自动指向下一段
            prev, curr = group_next, group_prev.next
            for _ in range(k):
                nxt = curr.next
                curr.next = prev
                prev, curr = curr, nxt

            # ③ 接回：新组头接锚点，锚点前移到新组尾
            tail = group_prev.next            # 旧组头 = 反转后的组尾
            group_prev.next = prev            # 新组头（原 kth）接上前一组
            group_prev = tail                 # 锚点移到组尾，进入下一组

        return dummy.next
```

### 手动推演：`[1,2,3,4,5], k = 2`

```
dummy → 1 → 2 → 3 → 4 → 5

第1组(k=2):
  探测: kth=2, group_next=3
  反转: prev从3开始, 反转1↔2 → 2→1→3→4→5
  接回: dummy.next=2, tail=1, group_prev=1

第2组:
  探测: kth=4, group_next=5
  反转: 3↔4 → 2→1→4→3→5
  接回: 1.next=4, tail=3, group_prev=3

第3组:
  探测: kth=5, 再走一步 kth=None → 不够2个
  return dummy.next = 2 → 1 → 4 → 3 → 5 ✓
```

### 为什么 prev 从 group_next 开始（核心技巧）

```
普通反转:    prev=None    反转后需手动把组尾接到 group_next
本变体:      prev=group_next  反转 k 次后，curr 停在组尾，
            而组尾.next 已在最后一轮被设为 prev(=group_next)
            → 自动接上下一段，少写一次连接
```

## 复杂度分析

- 时间复杂度：O(n)（探测与反转各遍历一遍，常数倍）
- 空间复杂度：O(1)

## 讨论记录

### 过程中的卡点

| 卡点 | 突破 |
|------|------|
| 无从下手 | 拆成"反转函数"+"主循环"两个职责；反转函数需返回新头和新尾两个值（本题用锚点 group_prev 承接） |
| 反转一段的 prev 起点别扭 | 不理解"prev 从 group_next 开始"的原因 —— 见上方核心技巧 |
| "够不够 k 个"的判定 | 先探测 k 步确认非空，不够直接 return；不能反转到一半才发现 |
| 组间连接 | 锚点模式：`tail = 旧组头`，`group_prev.next = 新组头`，`group_prev = tail` |
