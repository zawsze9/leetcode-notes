**模式标签**：单调队列
**状态**：思路正确但不能AC

## 题目描述

给定数组 `nums` 和窗口大小 `k`，返回每个滑动窗口的最大值。

## 关键思路

**单调递减双端队列**：保持队列索引对应的值严格递减，队首永远是当前窗口最大值。

> 每个元素最多入队出队各一次，整体 O(n)。核心操作：入队时从队尾踢掉所有比自己小的元素 —— 因为只要当前元素在窗口内，那些更小且更靠前的元素就永远不可能成为最大值。

## 代码实现

```python
from collections import deque

class Solution:
    def maxSlidingWindow(self, nums: List[int], k: int) -> List[int]:
        q = deque()   # 存索引，队列值严格递减
        ans = []

        for i, num in enumerate(nums):
            # 1. 队首滑出窗口，移除
            while q and q[0] <= i - k:
                q.popleft()

            # 2. 从队尾移除所有小于当前值的索引
            while q and nums[q[-1]] < num:
                q.pop()

            q.append(i)

            # 3. 窗口成型后记录队首
            if i >= k - 1:
                ans.append(nums[q[0]])

        return ans
```

### 手动推演：`nums = [1, 3, -1, -3, 5, 3], k = 3`

```
i=0, num=1   →  踢掉队首?无. 踢掉队尾?无. 入队 → q=[0]              窗口未成型
i=1, num=3   →  踢掉队首?无. 踢掉队尾?删0(1<3). 入队 → q=[1]        窗口未成型
i=2, num=-1  →  踢掉队首?无. 踢掉队尾?-1<3保留. 入队 → q=[1,2]       max = nums[1] = 3
i=3, num=-3  →  踢掉队首?无. 踢掉队尾?-3<-1保留. 入队 → q=[1,2,3]    max = 3
i=4, num=5   →  踢掉队首?1<=4-3=1 ✓ 删1. 踢掉队尾?删3,删2(<5). 入队 → q=[4]  max = 5
i=5, num=3   →  踢掉队首?无. 踢掉队尾?3<5保留. 入队 → q=[4,5]        max = 5

输出: [3, 3, 5, 5]
```

## 复杂度分析

- 时间复杂度：O(n)（每个元素最多入队一次出队一次）
- 空间复杂度：O(k)（队列最多存 k 个元素）

## 错误记录

### 初始错误代码

```python
class Solution:
    def maxSlidingWindow(self, nums: List[int], k: int) -> List[int]:
        ans = []
        n = len(nums)
        for l in range(n):
            r = l + k - 1
            if r <= n - 1:
                ans.append(max(nums[l:r+1]))
        return ans
```

### 错误分析

| 问题 | 说明 |
|------|------|
| **O(n×k) 超时** | 每个窗口调用 `max()` 扫描 k 个元素，n 和 k 均可达 10⁵，10¹⁰ 次操作必然超时 |

### 教训

| 场景 | 正确操作 |
|------|---------|
| 滑动窗口最大值 | 单调队列 O(1) 获取窗口最值 |
| 需要维持顺序的极值 | 入队时踢掉不如自己的旧元素（出队方向取决于窗口滑动） |

```python
# deque 用法
from collections import deque
q = deque()
q.append(i)       # 队尾入队
q.popleft()       # 队首出队
q.pop()           # 队尾出队
q[0]              # 取队首
q[-1]             # 取队尾

# while q  ← 等价于 while len(q) > 0，空容器为 False，非空为 True
```
