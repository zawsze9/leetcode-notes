# 148. Sort List

**模式标签**：链表归并排序（递归 / 自底向上）

**状态**：无思路（求助实现）

- **难度**：Medium
- **标签**：链表、归并排序、双指针、分治
- **链接**：https://leetcode.cn/problems/sort-list/

## 题目描述

在 O(n log n) 时间和 O(1) 空间内排序链表。

## 关键思路

**链表归并排序 = 找中点 + 递归切分 + 合并有序链表。** 三块全部是已学内容：快慢指针找中点（#141）、合并两个有序链表（#21 已 AC）、递归切分（切到空/单节点为止）。

> 数组归并要额外空间，链表归并只需改指针。递归版栈空间 O(log n)；迭代版（自底向上，按 1,2,4... 段长两两合并）可达 O(1) 空间。

## 代码实现

### 递归版（好想，栈空间 O(log n)）

```python
class Solution:
    def sortList(self, head: Optional[ListNode]) -> Optional[ListNode]:
        if not head or not head.next:
            return head

        # ① 快慢指针找中点，断开成两半
        slow, fast = head, head.next
        while fast and fast.next:
            slow = slow.next
            fast = fast.next.next
        mid = slow.next
        slow.next = None

        # ② 递归排序两半
        left = self.sortList(head)
        right = self.sortList(mid)

        # ③ 合并两个有序链表（#21 逻辑）
        dummy = ListNode()
        cur = dummy
        while left and right:
            if left.val <= right.val:
                cur.next = left
                left = left.next
            else:
                cur.next = right
                right = right.next
            cur = cur.next
        cur.next = left or right
        return dummy.next
```

### 迭代版（自底向上，O(1) 空间）

```python
class Solution:
    def sortList(self, head: Optional[ListNode]) -> Optional[ListNode]:
        if not head or not head.next:
            return head

        n = 0
        cur = head
        while cur:
            n += 1
            cur = cur.next

        dummy = ListNode(0, head)
        step = 1
        while step < n:
            prev, cur = dummy, dummy.next
            while cur:
                left = cur
                right = self._split(left, step)   # 切出第一段
                cur = self._split(right, step)    # 切出第二段
                prev = self._merge(left, right, prev)
            step *= 2
        return dummy.next

    def _split(self, head, step):
        # 从 head 数 step 个节点，返回下一段头并断开
        for _ in range(step - 1):
            if head:
                head = head.next
        if not head:
            return None
        nxt = head.next
        head.next = None
        return nxt

    def _merge(self, l1, l2, prev):
        # 把 l1、l2 合并到 prev 后面，返回合并后的尾
        cur = prev
        while l1 and l2:
            if l1.val <= l2.val:
                cur.next = l1
                l1 = l1.next
            else:
                cur.next = l2
                l2 = l2.next
            cur = cur.next
        cur.next = l1 or l2
        while cur.next:
            cur = cur.next
        return cur
```

### 手动推演：`[4, 2, 1, 3]`（递归版）

```
sortList(4→2→1→3):
  中点: 4 | 2→1→3 (断开)
  left  = sortList(4)       → 4
  right = sortList(2→1→3):
    中点: 2 | 1→3
    left  = sortList(2)     → 2
    right = sortList(1→3):
      中点: 1 | 3
      left  = 1, right = 3
      合并 → 1→3
    合并 2 和 1→3 → 1→2→3
  合并 4 和 1→2→3 → 1→2→3→4 ✓
```

## 错误记录

### 你的尝试：冒泡排序（超时 + bug）

```python
i = j = 0
while i < n:
    while j < n - i - 1:      # ← bug: j 只在循环外初始化一次
        if tmp.val > tmp.next.val:
            ...交换...
            j += 1
        else:
            ...
            j += 1
    i += 1
    prev = dummy
    tmp = dummy.next
```

### 错误分析

| 问题 | 说明 |
|------|------|
| **j 未在每轮重置** | 第一轮 j 走到 n-1，之后每轮 `j < n-i-1` 恒为 False，内层直接跳过 → 只冒泡了一轮 |
| **冒泡 O(n²) 必超时** | 题目要求 O(n log n)，n 达 5×10⁴ 时 n² ≈ 2.5×10⁹ 操作，即使修好 bug 也过不了 |
| **交换逻辑本身是对的** | 交换后 `prev,tmp=nxt,tmp` 正好对应数组冒泡"交换后继续比较下一对" |

### 教训

| 场景 | 正确选择 |
|------|---------|
| 排序链表 | 归并排序（O(n log n)），找中点 + 合并有序链表（已学模块拼装） |
| 循环内层变量 | 每轮外层循环开始前重置，别只在循环外初始化一次 |
| 看到"O(n log n)"要求 | 冒泡/插入/选择排序（O(n²)）直接排除 |
