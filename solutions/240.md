# 240. Search a 2D Matrix II

**模式标签**：Z 字形查找

**状态**：AC非最优

- **难度**：Medium
- **标签**：数组、二分查找、矩阵、分治
- **链接**：https://leetcode.cn/problems/search-a-2d-matrix-ii/

## 题目描述

每行升序、每列升序的矩阵中查找 target 是否存在。

## 关键思路

**从右上角出发，每次排除一行或一列。** `matrix[r][c] > target` 说明当前列全大于 target，整列排除（c -= 1）；`matrix[r][c] < target` 说明当前行全小于 target，整行排除（r += 1）。

> 本质是二叉搜索树的变体：以右上角为根，向左变小、向下变大。每次 O(1) 判断消掉一行或一列，总 O(m+n)。

## 代码实现

### 最优解：右上角出发 O(m+n)

```python
class Solution:
    def searchMatrix(self, matrix: List[List[int]], target: int) -> bool:
        m, n = len(matrix), len(matrix[0])
        r, c = 0, n - 1     # 右上角

        while r < m and c >= 0:
            if matrix[r][c] == target:
                return True
            elif matrix[r][c] > target:
                c -= 1       # 当前列全 > target，左移
            else:
                r += 1       # 当前行全 < target，下移

        return False
```

### 你的 AC 解法：展平查找 O(mn)

```python
class Solution:
    def searchMatrix(self, matrix: List[List[int]], target: int) -> bool:
        ans = []
        for row in matrix:
            ans.extend(row)
        if target in ans:
            return True
        else:
            return False
```
