# 226. Invert Binary Tree

**模式标签**：递归（后序遍历风格）

**状态**：AC且最优

- **难度**：Easy
- **标签**：树、递归、深度优先搜索
- **链接**：https://leetcode.cn/problems/invert-binary-tree/

## 题目描述

翻转二叉树（左右镜像）。

## 关键思路

**每个节点：交换左右孩子 + 递归翻转两个子树。** 递归自底向上完成，最终整棵树左右镜像。交换与递归的先后顺序不影响结果——因为两个子树都是整体翻转。

> 迭代版：层序遍历（BFS），每层节点逐个交换左右孩子，同样 O(n)。

## 代码实现

### 你的 AC 解法（标准递归）

```python
class Solution:
    def invertTree(self, root: Optional[TreeNode]) -> Optional[TreeNode]:
        if root is None:
            return None
        root.left, root.right = root.right, root.left
        self.invertTree(root.left)
        self.invertTree(root.right)
        return root
```

### 优化：终止条件统一返回

```python
class Solution:
    def invertTree(self, root: Optional[TreeNode]) -> Optional[TreeNode]:
        if root is None:
            return root          # None 时 root 本来就是 None
        root.left, root.right = root.right, root.left
        self.invertTree(root.left)
        self.invertTree(root.right)
        return root
```

### 手动推演

```
       4             4             4
      / \    交换    / \    递归   / \
     2   7  →       7   2  →     7   2
    / \ / \        / \ / \      / \ / \
   1 3 6 9        6 9 1 3      9 6 3 1

每层都交换左右，整棵树完成镜像。
```

## 复杂度分析

- 时间复杂度：O(n)（每个节点访问一次）
- 空间复杂度：O(树高)（递归栈）

## 讨论记录

### 关键点

| 点 | 说明 |
|----|------|
| 交换与递归顺序无关 | 左右子树整体翻转，先后不影响结果 |
| 终止条件 | 空树返回 None；由于 root 本身是 None，`return root` 两分支统一 |
| 递归模式 | "当前节点操作 + 子问题递归" 的又一实例 |
