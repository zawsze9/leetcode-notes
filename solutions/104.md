# 104. Maximum Depth of Binary Tree

**模式标签**：递归（树高）/ 层序遍历

**状态**：AC且最优

- **难度**：Easy
- **标签**：树、递归、广度优先搜索
- **链接**：https://leetcode.cn/problems/maximum-depth-of-binary-tree/

## 题目描述

返回二叉树的最大深度（根到最远叶子的节点数）。

## 关键思路

**树的高度 = 当前层（1）+ 左右子树较高的高度。** 递归模板"当前节点 + 子问题"的最直接应用，空树高度 0。

> 迭代版用层序遍历（BFS）：每处理完一层，深度 +1，直到队列为空。递归占用 O(树高) 栈空间，迭代占用 O(树宽) 队列空间。

## 代码实现

### 你的 AC 解法（等价于标准递归）

```python
class Solution:
    def maxDepth(self, root: Optional[TreeNode]) -> int:
        num = 0
        if root is None:
            return num
        num += 1
        num += max(self.maxDepth(root.left), self.maxDepth(root.right))
        return num
```

### 标准递归（更简洁）

```python
class Solution:
    def maxDepth(self, root: Optional[TreeNode]) -> int:
        if root is None:
            return 0
        return 1 + max(self.maxDepth(root.left), self.maxDepth(root.right))
```

### 迭代版：层序遍历（参考）

```python
class Solution:
    def maxDepth(self, root: Optional[TreeNode]) -> int:
        if root is None:
            return 0
        depth = 0
        q = [root]
        while q:
            depth += 1
            level = []
            for node in q:
                if node.left:
                    level.append(node.left)
                if node.right:
                    level.append(node.right)
            q = level
        return depth
```

### 手动推演

```
      3
     / \
    9  20
       / \
      15  7

maxDepth(3):
  = 1 + max(maxDepth(9), maxDepth(20))
  = 1 + max(1, 1 + max(maxDepth(15), maxDepth(7)))
  = 1 + max(1, 1 + max(1, 1))
  = 1 + max(1, 2)
  = 3 ✓
```

## 复杂度分析

| 方法 | 时间 | 空间 |
|------|------|------|
| 递归 | O(n) | O(树高) |
| 层序遍历 | O(n) | O(树宽) |

## 讨论记录

### 你的代码特点

逻辑正确，但把"1"先装进 `num` 再累加，写法绕了：

```
num = 0
num += 1            # 当前层
num += max(...)     # 子树最大深度
```

直接 `1 + max(...)` 一步表达，含义更清晰。

### 规律

| 递归模式 | 模板 |
|---------|------|
| 树高/深度 | `1 + max(左, 右)` |
| 返回值 | 空节点返回 0，非空返回组合结果 |
