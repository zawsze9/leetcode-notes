# 21. Merge Two Sorted Lists

**模式标签**：链表原地插入合并

**状态**：AC且最优

- **难度**：Easy
- **标签**：链表、递归、双指针
- **链接**：https://leetcode.cn/problems/merge-two-sorted-lists/

## 题目描述

将两个升序链表合并为一个升序链表，返回新链表头。

## 关键思路

**保持 a 为头更小的链表，把 b 链表的节点逐个插入 a 链的正确位置。** 内层循环找插入点（最后一个 `<= b.val` 的节点），然后 `a.next = b` 插入，`b` 指向被顶替的剩余部分，继续下一轮。直到 b 插完（`b is None`）或 a 走完。

> 与标准"双指针尾插"不同，这里用原地插入，复杂度相同：每个 a 节点最多被推进一次，每个 b 节点插入一次，总 O(n+m)。

## 代码实现

### 你的 AC 解法：原地插入

```python
class Solution:
    def mergeTwoLists(self, list1: Optional[ListNode], list2: Optional[ListNode]) -> Optional[ListNode]:
        a, b = list1, list2

        if a is None:
            return b
        if b is None:
            return a

        if b.val < a.val:
            a, b = b, a        # 保证 a 是头更小的链表
        ans = a                # 记录真正的头（可能被交换过）

        while a:
            if b is None:
                break          # b 全部插入完毕，a 链剩余部分已在链上
            while a.next and a.next.val <= b.val:
                a = a.next     # 找到插入点：最后一个 <= b.val 的节点
            c = a.next
            a.next = b         # 插入 b
            b = c              # b 指向被顶替的剩余部分

        return ans
```

### 标准写法：哨兵节点尾插（更简洁）

```python
class Solution:
    def mergeTwoLists(self, list1: Optional[ListNode], list2: Optional[ListNode]) -> Optional[ListNode]:
        dummy = ListNode()     # 哨兵节点，统一处理头
        cur = dummy
        while list1 and list2:
            if list1.val <= list2.val:
                cur.next = list1
                list1 = list1.next
            else:
                cur.next = list2
                list2 = list2.next
            cur = cur.next
        cur.next = list1 or list2   # 剩余部分直接接上
        return dummy.next
```

## 复杂度分析

- 时间复杂度：O(n+m)
- 空间复杂度：O(1)

## 错误记录

### 第一版错误代码

```python
while a:
    while a.next and a.next.val <= b.val:
        a = a.next
    c = a.next
    a.next = b
    b = c
    if a == None:
        return a     # 死代码 + 返回对象错误
return list1         # 交换头后返回错误
```

### 错误分析

| 问题 | 说明 |
|------|------|
| **`NoneType` 报错根因：控错对象** | 报错行是 `a.next.val <= b.val`，访问的是 `b.val`。当 list2 全部插入完毕，`b = c` 且 `c` 为 `None`，此时 `b` 变 `None`。外层 `while a:` 仍在跑，内层循环里 `a.next` 非空就访问 `b.val` → 崩溃 |
| **第 19 行 `if a == None: return a` 永远不生效** | `a` 在插入操作后**从未变为 None**（内层 while 推进的是 `a.next` 存在时的 `a`，且插入后 `a` 不变），会变 None 的是 `b`。判断对象完全错位 |
| **`return list1` 头丢失 bug** | 开头 `a, b = b, a` 交换后，合并链头是原 list2。若交换发生（list2 头更小），`return list1` 返回的是原 list1 的头，直接丢节点 |
| **`a == None and b == None` 分支冗余** | 前两个 `if a is None: return b` / `if b is None: return a` 已覆盖，该分支永远不可达 |

### 修复方案

| 修复点 | 做法 |
|--------|------|
| 解决 NoneType | 插入后判断 **`b` 是否为空**：`if b is None: break` |
| 解决头丢失 | `ans = a` 在交换后、循环前记录真正头，最后 `return ans` |
| 清理死代码 | 删除 `if a == None: return a`（无效且返回对象错误） |

### 教训

| 场景 | 提醒 |
|------|------|
| 报错指向 `NoneType.val` | 先定位哪个变量可能为 None，检查**它的**赋值路径，不要想当然控制别的变量 |
| 链表头会被移动/交换 | 头节点用哨兵节点或独立变量提前记录，不要依赖 `list1`/`list2` 原引用 |
| 循环内游标变量 | 明确谁在推进（`a`）、谁在消耗（`b`），分别判断各自的空态 |
