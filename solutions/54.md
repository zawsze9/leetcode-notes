# 54. Spiral Matrix

**模式标签**：边界收缩

## 题目描述

按顺时针螺旋顺序返回矩阵中的所有元素。

## 关键思路

**四个边界指针逐层收缩。** `top/bottom/left/right` 定义当前圈的范围，每读完一圈四边各往里缩一层。不破坏原矩阵，没有 pop 开销。

> 核心是判断 `top <= bottom` 和 `left <= right` 避免重复/越界。读上边后 `top += 1`，读右边后 `right -= 1`，读下边前要确认 `top <= bottom`（防止只有一行的矩阵读两次），读左边前同理。

## 代码实现

```python
class Solution:
    def spiralOrder(self, matrix: List[List[int]]) -> List[int]:
        m, n = len(matrix), len(matrix[0])
        top, bottom = 0, m - 1
        left, right = 0, n - 1
        ans = []

        while top <= bottom and left <= right:
            # 左→右（上行）
            for j in range(left, right + 1):
                ans.append(matrix[top][j])
            top += 1

            # 上→下（右列）
            for i in range(top, bottom + 1):
                ans.append(matrix[i][right])
            right -= 1

            # 右→左（下行），需判断非同一行
            if top <= bottom:
                for j in range(right, left - 1, -1):
                    ans.append(matrix[bottom][j])
                bottom -= 1

            # 下→上（左列），需判断非同一列
            if left <= right:
                for i in range(bottom, top - 1, -1):
                    ans.append(matrix[i][left])
                left += 1

        return ans
```

### 特殊形状判断的意义

```
单行矩阵 [[1,2,3,4]]:
  读上行 → ans=[1,2,3,4], top=1
  读右列 → top(1) > bottom(0) 跳过
  读下行 → top(1) > bottom(0) 跳过  ← 不加这个 if 会重复读
  读左列 → left(0) ≤ right(3) but top(1) > bottom(0) 跳过

单列矩阵 [[1],[2],[3]]:
  读上行 → ans=[1], top=1
  读右列 → ans=[1,2,3], right=-1
  读下行 → bottom(2) ≥ top(1) won't exec because right=-1
  其实就是 left=0 right=-1 循环结束
```

## 复杂度分析

- 时间复杂度：O(m × n)
- 空间复杂度：O(1)（不考虑输出数组）

### 错误分析

| 问题 | 说明 |
|------|------|
| **`pop(0)` 是 O(n)** | Python 列表 pop 首元素需移动所有后续元素，外层每圈都 call，大矩阵直接超时 |
| **清理空行循环逻辑混乱** | `len(matrix)` 随 pop 减少，但 j 一直递增，单列场景下 `matrix[0]` 始终为空 `[]`，每次 pop+1，循环边界不断变化导致死循环或效率极低 |
| **破坏原矩阵** | 边遍历边 pop/修改，追踪边界状态的复杂度爆炸 |
| **代码量过大难维护** | 拆分为四个方向的边界指针，每条边用 for 循环替代 while+pop，清晰且高效 |

### 教训

| 场景 | 策略 |
|------|------|
| 矩阵模拟（螺旋、旋转等） | 用四个边界指针 `top/bottom/left/right` 替代破坏性操作 |
| Python 列表操作 | 避免 `pop(0)` 和 `insert(0, x)`，都是 O(n) |
