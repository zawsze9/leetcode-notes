# 49. Group Anagrams

- **难度**：Medium
- **标签**：哈希表、字符串、排序
- **链接**：https://leetcode.cn/problems/group-anagrams/

## 题目描述

给定一个字符串数组，将字母异位词（字母相同但排列不同的词）归为一组，可以按任意顺序返回结果。

## 关键思路

字母异位词排序后相同，将排序结果作为哈希 key 进行分组

> 两个互为字母异位词的字符串，字符排序后得到相同结果。以排序字符串为 key，用字典将同一 key 的字符串归为一组即可。`defaultdict(list)` 省去手动判断 key 是否存在的步骤。

## 代码实现

```python
class Solution:
    def groupAnagrams(self, strs: List[str]) -> List[List[str]]:
        from collections import defaultdict
        d = defaultdict(list)
        for s in strs:
            d[''.join(sorted(s))].append(s)
        return list(d.values())
```

## 复杂度分析

- 时间复杂度：O(n * k log k)，n 为字符串数量，k 为最长字符串长度
- 空间复杂度：O(n * k)
