# 560. Subarray Sum Equals K

**模式标签**：前缀和 + 哈希表
**状态**：思路正确但不能AC

- **难度**：Medium
- **标签**：数组、哈希表、前缀和
- **链接**：https://leetcode.cn/problems/subarray-sum-equals-k/

## 题目描述

统计数组中和为 `k` 的连续子数组个数。

## 关键思路

**前缀和 + 哈希表计数**：`sum(nums[i..j]) = k` 等价于 `prefix[j] - prefix[i-1] = k`，即 `prefix[i-1] = prefix[j] - k`。

> 遍历时维护当前前缀和 `prefix`，对于每个位置 `j`，看之前有多少个 `prefix - k` 出现过的位置，这些位置到 `j` 之间就形成了和为 `k` 的子数组。哈希表 `{前缀和: 出现次数}` 实现 O(1) 查询。

## 代码实现

```python
class Solution:
    def subarraySum(self, nums: List[int], k: int) -> int:
        count = {0: 1}   # 前缀和为0出现1次，处理从索引0开始的子数组
        prefix = 0
        ans = 0

        for num in nums:
            prefix += num
            if prefix - k in count:
                ans += count[prefix - k]
            count[prefix] = count.get(prefix, 0) + 1

        return ans
```

## 复杂度分析

- 时间复杂度：O(n)
- 空间复杂度：O(n)

## 错误记录

### 初始错误代码

```python
class Solution:
    def subarraySum(self, nums: List[int], k: int) -> int:
        n = len(nums)
        ans = 0
        for l in range(n):
            for r in range(l, n):
                if sum(nums[l:r+1]) == k:
                    ans += 1
        return ans
```

### 错误分析

| 问题 | 说明 |
|------|------|
| **O(n³) 超时** | 两层循环 O(n²)，每次 `sum(nums[l:r+1])` 又 O(n)，总 O(n³)，n 最大 2×10⁴ 时直接崩 |
| **重复计算子数组和** | 每个窗口都重新求和，没有利用前后关联 |
| **前缀和可将 O(n³) → O(n)** | `sum[l..r] = prefix[r] - prefix[l-1]`，问题转化为在遍历中找之前出现过的 `prefix - k`，一次 O(n) 扫描即可 |

### 教训

子数组和问题 **第一反应想想前缀和**。配合哈希表做 **两数之差** 的查找，相当于将 "找所有区间和 = k" 转化为 "找两个前缀和之差 = k"，一次遍历 + O(1) 查询即可。

## 前缀和速查

```python
# prefix[i] = nums[0] + ... + nums[i]
# sum(nums[l..r]) = prefix[r] - prefix[l-1]

# 结论：
#   sum[l..r] = k  →  prefix[l-1] = prefix[r] - k
#   遍历到 r 时，去哈希表里查 "prefix[r] - k" 出现过几次
```

| 要点 | 记法 |
|------|------|
| `[l..r]` 的和 | `prefix[r] - prefix[l-1]` |
| 转化公式 | `prefix[l-1] = prefix[r] - k` |
| `{0: 1}` 初始化 | 处理从索引 0 开始的子数组（即 prefix[r] 本身就等于 k） |
| 本质 | 把"区间和"变成"两数之差"，O(n²) → O(n) |
