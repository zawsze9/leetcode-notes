# 199. Binary Tree Right Side View

**模式标签**：层序遍历（BFS+层快照）变式——每层取最后一个

**母题**：#102 Binary Tree Level Order Traversal（转折点见文末）

**状态**：AC非最优

**完成方式**：一遍通过

- **难度**：Medium
- **标签**：树、广度优先搜索、深度优先搜索
- **链接**：https://leetcode.cn/problems/binary-tree-right-side-view/

## 题目描述

给定二叉树根节点，想象自己站在树的右侧，返回从上到下能看到的所有节点值（每层最右边的一个）。

示例：

```text
输入：root = [1,2,3,null,5,null,4]

    1
   / \
  2   3
   \   \
    5   4

输出：[1,3,4]
```

## 关键思路

母题 #102 的层快照直接复用，**转折点只有一个**：每层只需要最后一个节点。

- 你的解法：完整跑层序、存下所有层的列表，再二次循环取每层 `[-1]`——结果对，但把"只要最后一个"用成了"全都要"
- 最优方向：在内层循环里按位置挑，`i == cnt - 1` 时记录即可，整层列表不必保存

## 代码实现

### 你的 AC 解法（全存层 + 取尾）

```python
class Solution:
    def rightSideView(self, root: Optional[TreeNode]) -> List[int]:
        if not root:
            return []
        d = deque([root])
        ans = []
        fans= []
        while d:
            tmpr = []
            for _ in range(len(d)):
                tmp = d.popleft()
                tmpr.append(tmp.val)
                if tmp.left:
                    d.append(tmp.left)
                if tmp.right:
                    d.append(tmp.right)
            ans.append(tmpr)
        for i in range(len(ans)) :
            fans.append(ans[i][-1])
        return fans
```

### 最优参考 1：层快照内直接记录每层最后一格

```python
class Solution:
    def rightSideView(self, root: Optional[TreeNode]) -> List[int]:
        if not root:
            return []
        d = deque([root])
        ans = []
        while d:
            cnt = len(d)
            for i in range(cnt):
                tmp = d.popleft()
                if i == cnt - 1:
                    ans.append(tmp.val)
                if tmp.left:
                    d.append(tmp.left)
                if tmp.right:
                    d.append(tmp.right)
        return ans
```

与你的版本几乎相同，`tmpr` 列表整个消失——"取巧解"到"最优解"只差这一处。

### 最优参考 2：DFS 根→右→左

```python
class Solution:
    def rightSideView(self, root: Optional[TreeNode]) -> List[int]:
        ans = []
        def dfs(node, depth):
            if not node:
                return
            if depth == len(ans):
                ans.append(node.val)
            dfs(node.right, depth + 1)
            dfs(node.left, depth + 1)
        dfs(root, 0)
        return ans
```

按根、右、左的顺序深度优先，每层**第一个**被访问到的节点就是最右节点；`depth == len(ans)` 判断"本层还没记录过"。

### 手动推演

```text
    1
   / \
  2   3
   \   \
    5   4
```

你的版本：

| 轮 | cnt | 本层 tmpr | ans | 循环后队列 |
|----|-----|-----------|-----|-----------|
| 1 | 1 | `[1]` | `[[1]]` | `[2, 3]` |
| 2 | 2 | `[2, 3]` | `[[1], [2, 3]]` | `[5, 4]` |
| 3 | 2 | `[5, 4]` | `[[1], [2, 3], [5, 4]]` | `[]` |

二次循环取尾 → `[1, 3, 4]` ✓。最优参考 1 在同一线路上第 3 步就直接产出 `[1, 3, 4]`，无中间列表。

## 复杂度分析

| 方法 | 时间 | 空间 |
|------|------|------|
| 全存层 + 取尾（你的） | O(n) | O(n)（全部层列表） |
| 层快照取尾格 | O(n) | O(w)，w 为最大层宽 |
| DFS 根右左 | O(n) | O(H) |

时间同为 O(n)（都要看每个节点），差距纯在空间：变式题只需要每层一个值，却存了每层全部值。
