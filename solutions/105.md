# 105. Construct Binary Tree from Preorder and Inorder Traversal

**模式标签**：前中序分治建树（#108 家族变式）

**母题**：#108 Convert Sorted Array to Binary Search Tree（转折点见文末）

**状态**：AC非最优

**完成方式**：纠错后通过

- **难度**：Medium
- **标签**：树、数组、分治、哈希表
- **链接**：https://leetcode.cn/problems/construct-binary-tree-from-preorder-and-inorder-traversal/

## 题目描述

给定二叉树的前序和中序遍历结果（节点值互不重复），重建这棵二叉树。

示例：

```text
输入：preorder = [3,9,20,15,7], inorder = [9,3,15,20,7]

    3
   / \
  9  20
     / \
    15  7
```

## 关键思路

两个数组各出一半信息：

| 数组 | 提供的信息 |
|------|-----------|
| 前序 | 第一个元素 = **根**；紧随其后的 m 个 = 左子树，其余 = 右子树 |
| 中序 | 根的位置 m：**左边 m 个 = 左子树，右边 = 右子树** |

分治结构（建树五段式，这题的教训核心）：

```text
基线（空数组 → None） → 建根 → 定位 m → 切分递归 → 返回 root
```

对比母题 #108：那题中序有序，根恰为中点，`len//2` 直接给出；这题根由前序给出，切分点 m 必须拿根值去中序里查——**前序出根，中序出边界**。

## 代码实现

### 你的 AC 解法（切片版）

```python
class Solution:
    def buildTree(self, preorder: list[int], inorder: list[int]) -> TreeNode | None:
        if not preorder:
            return None
        root = TreeNode(preorder[0])
        m = inorder.index(preorder[0])
        root.left = self.buildTree(preorder[1:1+m], inorder[:m])
        root.right = self.buildTree(preorder[1+m:], inorder[1+m:])
        return root
```

### 最优参考：哈希表 + 区间下标（#98 区间下传 × #108 索引版 的合体）

```python
class Solution:
    def buildTree(self, preorder: list[int], inorder: list[int]) -> TreeNode | None:
        idx = {v: i for i, v in enumerate(inorder)}   # 值 → 中序下标，index() 变 O(1)
        self.pre = 0                                   # 前序消费指针

        def build(lo: int, hi: int) -> TreeNode | None:
            if lo > hi:
                return None
            root = TreeNode(preorder[self.pre])
            m = idx[root.val]
            self.pre += 1
            root.left = build(lo, m - 1)
            root.right = build(m + 1, hi)
            return root

        return build(0, len(inorder) - 1)
```

三个要点：哈希表免去每次 O(n) 的 `index()`；区间代替切片免去每层 O(n) 拷贝；`self.pre` 是巧思——前序天然按"根→左→右"排列，而递归恰好先建左后建右，所以指针只进不退，消费顺序与建树顺序完全一致。

## 复杂度分析

| 方法 | 时间 | 空间 |
|------|------|------|
| 切片 + `index()`（你的） | 最坏 O(n²)（每层 index 与切片都是 O(n)，树倾斜时 n 层） | 累计拷贝最坏 O(n²)，活跃切片 O(n) |
| 哈希 + 区间（最优） | O(n) | O(n)（哈希表 + 递归栈） |

## 错误记录

### v1（global 版）

```python
leng=0
class Solution:
    def buildTree(self, preorder, inorder):
        global leng
        if not preorder:
            return None
        root = TreeNode(val=preorder[0])
        leng = inorder.index(preorder[leng])          # 下标语义失效
        root.left = self.buildTree(preorder[1:1+leng], inorder[leng+1:])   # 切片错 + 无 return
        root.right = self.buildTree(preorder[1+leng:], inorder[1+leng:])
```

### v2（越界版）

```python
m = inorder.index(preorder[0])    # 跑到基线前面 → 空切片时 preorder[0] 越界
if not preorder:
    return None
# 建根行丢失 → root.left 的 root 未定义
```

### 错误分析

| 版本 | 问题 | 说明 |
|------|------|------|
| v1 | global 做递归状态（根因） | ① 子层先改、父层后用：父层算 `root.right` 时的 `1+leng` 用的是左递归留下的值；② 子层拿父层遗留的 leng 当**下标**去查切片后的小数组，位置语义全错 |
| v1 | 左孩子 inorder 切片错 | 应为 `inorder[:m]`（根左边那半），写成 `inorder[m+1:]`（右半）——左右两个孩子拿到同一份右半 |
| v1 | 缺 `return root` | 主路径隐式返回 None，树建好也丢掉（#94/#114 纪律） |
| v2 | 基线不在第一行 | `index(preorder[0])` 在空检查前执行 → 空切片到来时越界。**基线之前的每行代码都会在空输入上执行一遍** |
| v2 | 建根行被误删 | `root` 未定义即使用 → NameError；编辑时整行丢失 |

### 教训

| 场景 | 做法 |
|------|------|
| 递归状态 | 用参数/局部变量，不用 global——每层有自己的数据（#108：切片即新对象） |
| 递归函数结构 | 基线永远第一行；主干语句放基线前，空输入替你执行它 |
| 建树题 | 五段式：基线 → 建根 → 定位 → 切分递归 → 返回 |
| 调试 | `print` 提交前删除 |

## Python 概念备忘

**global 在递归中的两宗罪**：① 跨层共享——递归深度上所有调用帧读写同一变量，父层在子层返回后读到的往往不是自己存的值；② 下标语义失效——把外层数组里算出的下标拿到切片后的子数组里用，位置全错。递归需要跨调用携带状态时，走**参数**（区间、指针）、**self 属性**（#98/#114/#230）或**返回值**，不走 global。

## 母题与转折点

**母题**：#108 Convert Sorted Array to Binary Search Tree（取中点分治建树家族）

**转折点**：#108 根 = 中点直接给出；#105 根 = 前序第一个元素，切分点 m 要靠中序里根的位置计算——**前序出根，中序出左右边界，两个数组各出一半信息**。

## 讨论记录

- v1 global 版输出错误：讲透全局变量两宗罪（子层改父层用 / 下标语义失效）、左孩子中序切片错、缺 return，配合 `[3,9,20,15,7]` 的污染过程推演。

- v3 AC。进阶指明哈希 + 区间 = #98 区间下传 × #108 索引版两条升级路径的合体。
- 定级：**AC非最优（纠错后通过）**；母子题登记为 #108 分治建树家族。
