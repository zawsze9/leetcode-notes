# 48. Rotate Image

**模式标签**：转置 + 水平翻转 / 四元素交换

**状态**：无思路

- **难度**：Medium
- **标签**：数组、数学、矩阵
- **链接**：https://leetcode.cn/problems/rotate-image/

## 题目描述

将 n×n 矩阵顺时针旋转 90 度，原地修改。

## 关键思路

**转置 + 水平翻转 = 顺时针旋转 90°。** `(i, j) → 转置 → (j, i) → 水平翻转 → (j, n-1-i)`，恰好等于顺时针旋转的效果。两步都可原地完成，代码简洁。

> 方法二：四元素原地交换，`(i, j) → (j, n-1-i) → (n-1-i, n-1-j) → (n-1-j, i)`，每四个位置构成一个循环，逐层逐组交换。

## 代码实现

### 方法一：转置 + 翻转（推荐记）

```python
class Solution:
    def rotate(self, matrix: List[List[int]]) -> None:
        n = len(matrix)

        # 1. 沿主对角线转置：交换 matrix[i][j] 和 matrix[j][i]
        for i in range(n):
            for j in range(i + 1, n):
                matrix[i][j], matrix[j][i] = matrix[j][i], matrix[i][j]

        # 2. 每行水平翻转
        for i in range(n):
            matrix[i].reverse()
```

### 方法二：四元素原地交换（逐层）

```python
class Solution:
    def rotate(self, matrix: List[List[int]]) -> None:
        n = len(matrix)
        for i in range(n // 2):                    # 第几圈
            for j in range(i, n - 1 - i):          # 圈内每四个一组
                tmp = matrix[i][j]
                matrix[i][j] = matrix[n - 1 - j][i]
                matrix[n - 1 - j][i] = matrix[n - 1 - i][n - 1 - j]
                matrix[n - 1 - i][n - 1 - j] = matrix[j][n - 1 - i]
                matrix[j][n - 1 - i] = tmp
```

### 四元素交换图解（一层）

```
n=4, i=0 这一层:

四个位置构成一个循环:
  matrix[0][0] → matrix[0][3] → matrix[3][3] → matrix[3][0] → matrix[0][0]
      左上角    ←    右上角    ←    右下角    ←    左下角    ←   (回归)

一次交换同时搬移四个位置，j 从 0 到 n-2 遍历该层的每个起点:

j=0: [0][0]←[3][0]←[3][3]←[0][3]←tmp([0][0])
```

## 思路卡点分析

### 为什么沿用螺旋矩阵的边界方式行不通

螺旋矩阵是 **顺序遍历**（沿边逐个 append），不用关心元素最终去哪。旋转是 **重新映射**，每个元素需要移动到新坐标。

| 螺旋遍历 | 旋转 |
|---------|------|
| 只看当前元素是什么，append 走人 | 必须知道当前元素的**目标位置** |
| `top/bottom/left/right` 管遍历顺序 | 需要知道 `(i,j) → (?,?)` 的映射公式 |

核心公式：`(i, j) → (j, n-1-i)`，用转置+翻转或四元交换实现。
