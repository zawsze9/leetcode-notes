# 189. Rotate Array

**模式标签**：三次反转
**状态**：AC非最优

- **难度**：Medium
- **标签**：数组、数学、双指针
- **链接**：https://leetcode.cn/problems/rotate-array/

## 题目描述

将数组向右旋转 k 步，原地修改。

## 关键思路

**三次反转**：`[1,2,3,4,5,6,7] k=3 → 整个反转 → 前 k 个反转 → 后 n-k 个反转`。

> `pop` + `insert(0)` 每次都是 O(n)，k 次即 O(kn)。三次反转全部是 O(n) 且原地完成。

## 代码实现

### 最优解：三次反转 O(n) 时间 + O(1) 空间

```python
class Solution:
    def rotate(self, nums: List[int], k: int) -> None:
        k %= len(nums)   # k 可能 > n

        def reverse(l, r):
            while l < r:
                nums[l], nums[r] = nums[r], nums[l]
                l += 1
                r -= 1

        n = len(nums)
        reverse(0, n - 1)       # 1. 整个反转
        reverse(0, k - 1)       # 2. 前 k 个反转
        reverse(k, n - 1)       # 3. 后 n-k 个反转
```

### 你的 AC 解法：逐次 pop + insert（O(kn)）

```python
class Solution:
    def rotate(self, nums: List[int], k: int) -> None:
        i = 0
        while i < k:
            a = nums.pop()
            nums.insert(0, a)   # insert(0) 会移动所有元素，O(n)
            i += 1
```

## 手动推演：`nums = [1,2,3,4,5,6,7], k = 3`

```
原始:        [1, 2, 3, 4, 5, 6, 7]
整个反转:    [7, 6, 5, 4, 3, 2, 1]
前3个反转:   [5, 6, 7, 4, 3, 2, 1]
后4个反转:   [5, 6, 7, 1, 2, 3, 4]  ✓
```

**直觉**：想象把数组切成 `[-k部分] [k部分]`，整个反转让两部分都到另一端但顺序反了，再各自反转恢复顺序。

## 复杂度分析

| 方法 | 时间 | 空间 |
|------|------|------|
| pop + insert | O(kn) | O(1) |
| 三次反转 | O(n) | O(1) |
