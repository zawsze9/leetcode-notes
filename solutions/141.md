# 141. Linked List Cycle

**模式标签**：快慢指针 / Floyd 判圈

**状态**：AC非最优

- **难度**：Easy
- **标签**：链表、双指针、哈希表
- **链接**：https://leetcode.cn/problems/linked-list-cycle/

## 题目描述

判断链表中是否存在环。

## 关键思路

**快慢指针（Floyd 判圈）：快指针每次走两步，慢指针每次走一步。** 若有环，两者必然相遇；若链表走完遇到 None，则无环。

> 环内快指针每次比慢指针多走一步，两者的距离差以 1 递减，最终必相遇。O(1) 空间，不需要记录访问过的节点。

## 代码实现

### 最优解：快慢指针 O(1) 空间

```python
class Solution:
    def hasCycle(self, head: Optional[ListNode]) -> bool:
        slow = fast = head

        while fast and fast.next:
            slow = slow.next          # 走一步
            fast = fast.next.next     # 走两步
            if slow == fast:
                return True

        return False
```

### 你的 AC 解法：哈希记录 O(n) 空间

```python
class Solution:
    def hasCycle(self, head: Optional[ListNode]) -> bool:
        seen = []
        while head:
            if head in seen:
                return True
            seen.append(head)
            head = head.next
        return False
```

### 快慢指针图解

```
链: 3 → 2 → 0 → 4
         ↑       ↓
         └── 2 ←─┘

第1步: slow=2  fast=0
第2步: slow=0  fast=2
第3步: slow=4  fast=4  ← 相遇! 有环
```

```
无环: 1 → 2 → 3 → None
  fast 走到 None → 循环结束，返回 False
```

### 为什么必然相遇

```
假设环长 L，快慢指针入环后相距 d
每轮: 快多走 1 步，d 减少 1
经过 L 轮后 d=0，必然相遇
```

## 复杂度分析

| 方法 | 时间 | 空间 |
|------|------|------|
| 快慢指针 | O(n) | O(1) |
| 哈希记录 | O(n) | O(n) |
