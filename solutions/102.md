# 102. Binary Tree Level Order Traversal

**模式标签**：层序遍历（BFS 队列 + 层快照）

**状态**：AC且最优

**完成方式**：纠错后通过

- **难度**：Medium
- **标签**：树、广度优先搜索、队列
- **链接**：https://leetcode.cn/problems/binary-tree-level-order-traversal/

## 题目描述

给你二叉树的根节点 `root`，返回其节点值的**层序遍历**（即逐层地、从左到右访问所有节点），结果为嵌套列表——每一层是一个子列表。

示例：

```text
输入：root = [3,9,20,null,null,15,7]
输出：[[3],[9,20],[15,7]]

    3
   / \
  9  20
     / \
    15  7
```

## 关键思路

BFS 用队列逐个出队入队，但队列本身**不携带"谁属于第几层"的信息**——所有节点混在一起。核心技巧是**层快照**：

- 每一轮开始前，队列里恰好只有当前一层的节点（上一层的都弹完了，下一层的还没入）
- 因此 `cnt = len(d)` 固定下来的瞬间，`cnt` 就是本层节点数
- 内层循环**恰好弹出 `cnt` 个**，收进本层列表；期间产生的子节点入队，留给下一层
- 外层 `while d` 管层，内层 `for range(cnt)` 管层内节点

配套纪律：**只把真实存在的节点入队**（含根节点）。队列里混入 `None` 占位值后，"队列非空"就不再等于"还有真实节点"，`while d` 的终止条件会被污染。

## 代码实现

### 你的 AC 解法（即标准最优解）

```python
class Solution:
    def levelOrder(self, root: Optional[TreeNode]) -> List[List[int]]:
        d = deque()
        ans = []
        d.append(root)
        tmp = root
        if not tmp:
            return []
        while d:
            cnt = len(d)
            tmpr = []
            for i in range(cnt):
                tmp = d.popleft()
                if tmp:
                    tmpr.append(tmp.val)
                    if tmp.left:
                        d.append(tmp.left)
                    if tmp.right:
                        d.append(tmp.right)
            ans.append(tmpr)
        return ans
```

两个可再打磨的小点（不影响正确性）：

1. `d.append(root)` 放在判空之前，那一下 append 是死代码；改成 `if root: d.append(root)` 后空树时队列天然为空，专门的判空分支都可以省掉
2. 出队侧的 `if tmp:` 在入队侧判空后永远不会为假，可删；`tmp = root` 赋值后立刻被覆盖，冗余

### 优化后的最简洁写法

```python
class Solution:
    def levelOrder(self, root: Optional[TreeNode]) -> List[List[int]]:
        if not root:
            return []
        d = deque([root])
        ans = []
        while d:
            tmpr = []
            for _ in range(len(d)):
                tmp = d.popleft()
                tmpr.append(tmp.val)
                if tmp.left:
                    d.append(tmp.left)
                if tmp.right:
                    d.append(tmp.right)
            ans.append(tmpr)
        return ans
```

对照你的 AC 版本，改动点：

| 原版 | 优化版 | 说明 |
|------|--------|------|
| `d.append(root)`、`tmp = root`、`if not tmp: return []` 三步散落 | `if not root: return []` 开头一刀 + `deque([root])` 直接初始化 | 空树在入口处理完，后续代码不再操心 `root` 为 `None` |
| `cnt = len(d)` 单独一行 | `for _ in range(len(d))` 内联 | `range` 在进入 for 循环那一刻求值一次，天然就是快照，省一个变量 |
| 出队侧 `if tmp:` 判空 | 删除 | 入队侧判空后队列里只有真实节点，防御分支永不触发 |

复杂度不变：O(n) / O(n)。

### 手动推演

```text
      3
     / \
    9  20
       / \
      15  7
```

| 轮 | cnt（快照） | 内层弹出 | 本层 tmpr | 循环后队列 | ans |
|----|------------|---------|-----------|-----------|-----|
| 初始 | — | — | — | `[3]` | `[]` |
| 1 | 1 | 3 | `[3]` | `[9, 20]` | `[[3]]` |
| 2 | 2 | 9, 20 | `[9, 20]` | `[15, 7]` | `[[3], [9, 20]]` |
| 3 | 2 | 15, 7 | `[15, 7]` | `[]` | `[[3], [9, 20], [15, 7]]` |

第 2 轮中 9 没有孩子、20 产生 15 和 7——子节点在上一层处理时入队，等到下一轮快照时队列里恰好是完整的一层。

## 复杂度分析

| 方法 | 时间 | 空间 |
|------|------|------|
| BFS + 层快照 | O(n) | O(n) |

每个节点恰好进出队一次；队列最多存一层节点，最坏情况（满树最后一层）约 n/2 个。层序遍历必须访问全部 n 个节点，已是最优。

## 错误记录

### 初始错误代码（v1：拍平的一维列表）

```python
while d:
    tmp = d.popleft()
    if tmp:
        ans.append(tmp.val)        # 所有值进同一个列表
        d.append(tmp.left)
        d.append(tmp.right)
return ans                         # 返回 [3,9,20,15,7]，一维
```

### 第二版（v2：多一行空层）

```python
while d:
    cnt = len(d)                   # 快照被 None 污染
    tmpr = []
    for i in range(cnt):
        tmp = d.popleft()
        if tmp:
            tmpr.append(tmp.val)
            d.append(tmp.left)     # None 也入队
            d.append(tmp.right)
    ans.append(tmpr)               # 全 None 的轮产出空层
return ans                         # 单节点 [1] 返回 [[1], []]
```

### 错误分析

| 版本 | 问题 | 说明 |
|------|------|------|
| v1 | 返回结构错误（根因） | 题目要按层分组的嵌套列表，代码把所有值拍平进一个列表；遍历顺序完全正确，缺的是"层"的分组依据 |
| v1 | 队列不携带层信息 | 所有节点混在一个队列里，无法区分谁属于第几层 |
| v2 | None 占名额 | 入队未判空，`None` 虚增快照 `cnt`；最后一轮队列全是 `None`，无条件 `ans.append(tmpr)` 产出空层，多一行 `[]` |
| v2 | 根节点入队位置 | `d.append(root)` 放在判空 `return` 之前，append 成为死代码；空树靠专门分支绕行而非根治 |

### 教训

| 场景 | 做法 |
|------|------|
| BFS 需要按层分组 | 层快照：内层循环前 `cnt = len(d)` 固定，恰好弹出 `cnt` 个为一层 |
| 循环边界在循环中变化 | 快照必须在进入内层循环前取，不能拿实时 `len(d)` 当内层条件 |
| 队列驱动的 `while` 终止条件 | 只把真实节点入队；队列混入占位值后"非空"≠"有活干" |
| 可空引用进队列 | 入队侧判空（含初始根节点），而不是出队侧过滤 |
| 想在出口处过滤空层 | 歪招——"用过滤掩盖问题而非修根源"（同 #94 的 `cleaned`） |

## Python 概念备忘

`while d` 对 deque **只看长度、不看内容**：`deque([None])` 长度为 1，是真值，循环照样执行。这就是 v2 幽灵空轮的直接原因——`d` 里有 `None` 不代表队列为空。

`for _ in range(len(d))` 里的 `len(d)` 在**进入 for 循环的那一刻求值一次**，之后循环体内 `d` 变长变短都不影响本轮的循环次数——所以内联写 `len(d)` 天然就是层快照。对比 `while i < len(d)` 这类条件，每一轮都重新求值，位置放错就会多循环或越界。优化版敢把 `len(d)` 直接写进 `range`，靠的就是这个求值时机。

## 讨论记录

- v1：遍历顺序正确但返回拍平列表；指出根因（缺层信息）与层快照方向。
- v2：双层循环结构对了，但 `None` 入队污染快照，单节点 `[1]` 就能复现 `[[1], []]`；指出入队侧判空 + 根节点判空。
- v3：AC。突破点在于理解"队列非空 ≠ 还有真实节点"，判定为"AC且最优（纠错后通过）"。
