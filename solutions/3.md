# 3. Longest Substring Without Repeating Characters

**模式标签**：滑动窗口

- **难度**：Medium
- **标签**：哈希表、字符串、滑动窗口
- **链接**：https://leetcode.cn/problems/longest-substring-without-repeating-characters/

## 题目描述

找出字符串中不含重复字符的最长子串长度。

## 关键思路

**滑动窗口 + 哈希表记录最近位置**：维护一个无重复字符的窗口 `[left, right]`，右指针不断扩展，遇到重复字符时将左指针跳到重复字符上次出现位置之后。

> 核心：不是"遇到重复就清空重来"，而是"遇到重复就把左端收缩到上一次出现该字符的后面"。这样窗口始终无重复，且尽可能大。

## 代码实现

```python
class Solution:
    def lengthOfLongestSubstring(self, s: str) -> int:
        last = {}       # char -> 上次出现的索引
        left = 0
        ans = 0

        for right, c in enumerate(s):
            # 如果 c 在当前窗口内出现过，左指针跳到它的下一个位置
            if c in last and last[c] >= left:
                left = last[c] + 1
            last[c] = right
            ans = max(ans, right - left + 1)

        return ans
```

**`last[c] >= left` 的作用**：确保该字符确实出现在当前窗口内，而不是窗口之外的历史记录。

## 复杂度分析

- 时间复杂度：O(n)
- 空间复杂度：O(1)（字符集最多 128 个 ASCII / 取决于字符集大小）

## 错误记录

### 初始错误代码

```python
class Solution:
    def lengthOfLongestSubstring(self, s: str) -> int:
        ans1 = 0
        ans2 = 1
        seen = set()
        for c in s:
            if c not in seen:
                ans1 += 1
                seen.add(c)
            elif c in seen:
                seen.clear()
                ans2 = max(ans1, ans2)
                ans1 = 1
                seen.add(c)
            ans2 = max(ans1, ans2)
        return ans2
```

### 错误分析

| 问题 | 说明 |
|------|------|
| **遇到重复就清空重来，丢失有效字符** | 对于 `"dvdf"`，遇到第二个 `d` 时清空 set 从当前 `d` 重新计数，丢失了前面的 `v`，正确做法是将左端收缩到第一个 `d` 后面，窗口变为 `[v, d]` |
| **用 set 而非 dict 记录位置** | set 只知道"出现过"但不知道"在哪里出现过"，无法实现左指针的精确跳转 |
| **逻辑混乱** | `ans2` 初始化为 1 但空字符串应返回 0，用两个变量 `ans1`/`ans2` 分别追踪当前和全局最大，不如单一 `ans` 配合左指针直观 |

### Bug 推演：`"dvdf"`

```
你的代码:
  d → seen={d},     ans1=1
  v → seen={d,v},   ans1=2
  d → 重复! 清空,   ans1=1, seen={d}
  f → seen={d,f},   ans1=2
  输出: 2  ✗

正确做法:
  d → window=[d],     last={d:0}, ans=1
  v → window=[d,v],   last={d:0,v:1}, ans=2
  d → 重复! left移到v位置, window=[v,d], last={d:2,v:1}, ans=2
  f → window=[v,d,f], last={d:2,v:1,f:3}, ans=3
  输出: 3  ✓
```

### 教训

滑动窗口的核心是 **左右指针同步维护**，右指针扩展、左指针只在必要时收缩。用 `dict` 记录字符最近出现位置，就能知道左指针该跳到哪。避免用 `set` + 清空 的"暴力重来"思路。
