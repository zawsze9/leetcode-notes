# 108. Convert Sorted Array to Binary Search Tree

**模式标签**：取中点分治建平衡 BST

**状态**：AC非最优

**完成方式**：纠错后通过

- **难度**：Easy
- **标签**：树、数组、分治、二叉搜索树
- **链接**：https://leetcode.cn/problems/convert-sorted-array-to-binary-search-tree/

## 题目描述

给定升序数组 `nums`，将其转换为**高度平衡**的二叉搜索树（每个节点左右两个子树的高度差的绝对值不超过 1）。答案不唯一，返回任意一个合法解即可。

示例：

```text
输入：nums = [-10,-3,0,5,9]
输出：[0,-3,9,-10,null,5]（多种合法答案之一）
```

## 关键思路

两个性质拼起来：

| 性质 | 推论 |
|------|------|
| 高度平衡 → 左右子树规模要尽量对称 | 取**中点**做根，左右两半规模最多差 1 |
| 数组升序 → 中点左边全小于它、右边全大于它 | 以中点为根天然满足 BST 性质，无需任何额外检查 |

于是形成分治结构：

- `mid = len(nums) // 2`，建根节点
- `nums[:mid]` 递归建左子树，`nums[mid+1:]` 递归建右子树
- 基线：空数组返回 `None`

**终止性论证**（不是碰运气）：设某层参数长度为 L ≥ 1，则左切片长 mid ∈ [0, L-1]，右切片长 L-mid-1 ∈ [0, L-1]，两者都**严格小于 L 且非负**。长度逐层严格递减，必然切出 0 命中基线。

## 代码实现

### 你的 AC 解法（切片版）

```python
class Solution:
    def sortedArrayToBST(self, nums: List[int]) -> Optional[TreeNode]:
        if not nums:
            return None
        root = TreeNode(val=nums[len(nums)//2])
        root.left = self.sortedArrayToBST(nums[0:len(nums)//2])
        root.right = self.sortedArrayToBST(nums[len(nums)//2+1:])
        return root
```

小打磨点：`len(nums)//2` 抄了三遍，存成 `mid` 变量（同 #2"进位写三遍"的教训）——这次 v1 漏包 `int()` 正是抄写不一致的产物。

### 最优参考：索引边界版（免切片拷贝）

```python
class Solution:
    def sortedArrayToBST(self, nums: List[int]) -> Optional[TreeNode]:
        def build(lo: int, hi: int) -> Optional[TreeNode]:
            if lo > hi:
                return None
            mid = (lo + hi) // 2
            node = TreeNode(nums[mid])
            node.left = build(lo, mid - 1)
            node.right = build(mid + 1, hi)
            return node
        return build(0, len(nums) - 1)
```

传左右下标而不是切片：区间用完即弃，不产生任何新列表。这是"AC非最优"定级的由来——算法思想完全相同，差距纯在切片拷贝（见复杂度）。

### 手动推演

```text
nums = [-10, -3, 0, 5, 9]
```

| 调用 | nums | mid | 建根 | 左切片 | 右切片 |
|------|------|-----|------|--------|--------|
| A | [-10,-3,0,5,9] | 2 | 0 | [-10,-3] | [5,9] |
| B（A 左） | [-10,-3] | 1 | -3 | [-10] | [] |
| C（A 右） | [5,9] | 1 | 9 | [5] | [] |
| B1（B 左） | [-10] | 0 | -10 | [] | [] |
| B2 / C2（叶子子调用） | [] | — | **return None** | — | — |

```text
      0
     / \
   -3   9
   /   /
 -10  5
```

注意 B、C 两层的右切片 `[]` 和 B1 的左右切片 `[]`——每个叶子节点的 `None` 孩子都来自基线分支。

## 复杂度分析

| 方法 | 时间 | 空间 |
|------|------|------|
| 切片版（你的实现） | O(n log n)（切片拷贝主导；建树本身 O(n)） | O(n)（任一时刻活跃切片沿路径总量 ≈ 2n；递归栈 O(log n)） |
| 索引版（最优参考） | O(n) | O(log n)（不含输出树） |

切片版每层把全部元素复制一遍，共 log n 层：T(n) = O(n) + 2T(n/2) → O(n log n)。索引版只移动下标，每个元素恰好建一次节点，严格 O(n)。

## 错误记录

### 初始错误代码

```python
if not nums:
    return []                                     # 类型不一致
root = TreeNode(val=nums[int(len(nums)/2)])
if not root:                                      # 死代码
    return
root.left = self.sortedArrayToBST(nums[0:len(nums)/2])    # float 切片 → TypeError
root.right = self.sortedArrayToBST(nums[len(nums)/2+1:])  # 同上
return root
```

### 错误分析

| 问题 | 说明 |
|------|------|
| 切片索引用 `/`（直接报错元凶） | Python 3 真除法返回 float（5/2=2.5），切片索引必须是整数 → `TypeError: slice indices must be integers`；中点取值包了 `int()`，两个切片没包——同一表达式抄三遍，处理不统一 |
| 空输入返回 `[]` | 与正常分支的 `TreeNode` 类型不一致，空树应返回 `None`。#94"返回值类型不一致"（None vs []）换个方向再犯 |
| `if not root: return` 死代码 | `root` 是上一行刚 `TreeNode(...)` 构造的对象，永不为 `None`；该分支永不触发，且它从来不是递归的终止条件 |

### 教训

| 场景 | 做法 |
|------|------|
| 切片/索引运算 | 用 `//` 整除；同一中点值存成 `mid` 变量，不要把表达式抄多遍 |
| 空输入返回值 | 与正常分支同类型：树题返回 `None`，列表题返回 `[]` |
| 判断递归终止条件在哪 | 看函数开头对**哪个参数**做了 if 检查——那个参数就是递归变量；检查本层刚构造的对象不是终止条件 |
| 递归必然终止的判据 | 每层参数严格变小且非负，必然到达基线 |

## Python 概念备忘

| 写法 | 结果 | 说明 |
|------|------|------|
| `5 / 2` | `2.5`（float） | Python 3 真除法，不截断 |
| `5 // 2` | `2`（int） | 整除，向下取整（负数时 `-5 // 2 == -3`） |
| `nums[0:2.5]` | TypeError | 切片索引只认整数 |

**切片是新列表，不是引用**：`nums[:mid]` 复制出一份新对象，作为子调用的参数。子帧里的 `nums` 与原列表解耦——递归终止看的不是"原列表有没有被改"，而是"每层参数是不是在层层变小"。

**`return None` 触发得极频繁**：每个叶子节点的两个 `None` 孩子都由基线分支返回（单元素 `[1]` 就触发两次）。"队列非空 ≠ 有活干"（#102）与"'没看到执行' ≠ 不触发"，都是要盯住变量的实际取值而不是凭感觉。

## 讨论记录

- v1：思路正确（中点为根、左右半分治），实现层三个问题：float 切片报错、空返回类型不一致、死代码判空。指出后修复，AC。
- 关键追问："把 `not root` 删了不是没终止条件了吗？递归只是切片不改变 nums，`return None` 也不触发吧？"——两个误解当场拆解：① 切片不修改原列表，但切片结果是**新列表**、是子调用的参数，终止靠参数层层变小；② `return None` 是整棵树所有 `None` 孩子的来源，`[1]` 单元素即触发两次。真正的终止条件是第一行 `if not nums`。
- 定级讨论：切片版有 O(n log n) 拷贝开销，索引边界版严格 O(n)，故记 **AC非最优（纠错后通过）**，算法思想（取中点分治）本身已是最优方向。
