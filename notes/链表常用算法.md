## 〇、节点定义

```python
class ListNode:
    def __init__(self, val=0, next=None):
        self.val = val
        self.next = next
```

**核心认知**：链表只有两类操作 —— 改 `next` 指向、移动指针。所有题目都是这两件事的组合。

---

## 一、反转（最重要，三种变体）

### 变体 1：整体反转（prev 从 None 开始）

```python
def reverse(head):
    prev, curr = None, head
    while curr:
        nxt = curr.next
        curr.next = prev
        prev, curr = curr, nxt
    return prev    # 新头
```

要点：提前 `nxt = curr.next` 保住后面不断链；返回 prev（新头）。

### 变体 2：反转一段并接回（prev 从"段尾的 next"开始）

```python
# 反转 [start, kth] 这 k 个节点，段后紧跟 group_next
def reverse_k(start, k, group_next):
    prev, curr = group_next, start   # prev 从段外开始
    for _ in range(k):
        nxt = curr.next
        curr.next = prev
        prev, curr = curr, nxt
    return prev    # 新段头；同时旧段头已自动指向 group_next
```

关键技巧：**prev 初始化为 group_next 而不是 None**，反转结束后旧段头自动指向下一段，省掉一次连接。

### 变体 3：K 个一组反转（变体 2 + 探测 + 锚点）

```python
def reverseKGroup(head, k):
    dummy = ListNode(0, head)
    group_prev = dummy

    while True:
        # ① 探测：检查是否够 k 个
        kth = group_prev
        for _ in range(k):
            kth = kth.next
            if not kth:
                return dummy.next
        group_next = kth.next

        # ② 组内反转（变体 2）
        prev, curr = group_next, group_prev.next
        for _ in range(k):
            nxt = curr.next
            curr.next = prev
            prev, curr = curr, nxt

        # ③ 接回
        tail = group_prev.next     # 旧组头 = 新组尾
        group_prev.next = prev     # 接上新组头
        group_prev = tail          # 锚点前移

```

三个环节对应三个模式：探测（先数后做）、反转（变体 2）、锚点连接（dummy + 组尾）。

### 反转速记

| 场景 | prev 起点 | 返回 |
|------|-----------|------|
| 整体反转 | None | 新头 |
| 反转一段接回 | 段尾的 next | 新段头 |
| K 个一组 | 每组的 next 段起点 | 新组头 |

## 二、遍历与长度

```python
# 遍历（获取长度、末节点）
cur = head
num = 0
while cur:
    num += 1
    cur = cur.next

# 取值模板（不等长时的常见写法）
v = cur.val if cur else 0   # None 视为 0
cur = cur.next if cur else None
```

**计数容易错位**：`while cur:` 数的是节点数；`while cur.next:` 停在末节点。想清楚要停在哪。

## 三、快慢指针（五个用途）

### 1. 判断有环

```python
slow = fast = head
while fast and fast.next:
    slow = slow.next
    fast = fast.next.next
    if slow == fast:
        return True
return False
```

### 2. 找环入口（相遇后再走）

```python
while fast and fast.next:
    slow = slow.next
    fast = fast.next.next
    if slow == fast:
        fast = head
        while slow != fast:
            slow = slow.next
            fast = fast.next
        return slow
return None
```

### 3. 找中点（回文/分割）

```python
slow = fast = head
while fast and fast.next:
    slow = slow.next
    fast = fast.next.next
# slow 即中点（偶数个时偏右）
```

### 4. 找倒数第 k 个（快先走 k 步）

```python
fast = slow = head
for _ in range(k):
    fast = fast.next
while fast:
    fast = fast.next
    slow = slow.next
# slow 即倒数第 k 个
```

### 5. 删除倒数第 k 个（快先走 k+1 步，slow 停在前驱）

```python
dummy = ListNode(0, head)
fast = slow = dummy
for _ in range(k + 1):
    fast = fast.next
while fast:
    fast = fast.next
    slow = slow.next
slow.next = slow.next.next
return dummy.next
```

> 规律：快慢指针的距离差 = 你想让 slow 与尾部的距离。删除要多走一步因为要停在前驱。

## 四、合并 / 插入模板

### 合并两个有序链表（哨兵尾插）

```python
def mergeTwoLists(list1, list2):
    dummy = cur = ListNode()
    while list1 and list2:
        if list1.val <= list2.val:
            cur.next = list1
            list1 = list1.next
        else:
            cur.next = list2
            list2 = list2.next
        cur = cur.next
    cur.next = list1 or list2   # 剩余直接接上
    return dummy.next
```

## 五、删除模板

### 删除指定前驱的下一个

```python
prev.next = prev.next.next
```

**铁律**：删除必须先找到**前驱**，前驱靠"走 L-n 步"或"快慢差"定位，而不是直接定位被删节点。

## 六、判断类

### 回文（快慢找中点 + 反转后半 + 比较）

```python
def isPalindrome(head):
    slow = fast = head
    while fast and fast.next:
        slow = slow.next
        fast = fast.next.next

    prev = None
    while slow:              # 反转后半
        nxt = slow.next
        slow.next = prev
        prev = slow
        slow = nxt

    left, right = head, prev
    while right:
        if left.val != right.val:
            return False
        left, right = left.next, right.next
    return True
```

### 相交（交换跑道）

```python
def getIntersectionNode(headA, headB):
    pA, pB = headA, headB
    while pA != pB:
        pA = pA.next if pA else headB
        pB = pB.next if pB else headA
    return pA
```

## 七、复杂度速查

| 操作 | 时间 | 空间 | 关键点 |
|------|------|------|--------|
| 反转 | O(n) | O(1) | nxt 先存 |
| K 个一组反转 | O(n) | O(1) | 探测 + 变体2 + 锚点 |
| 判环 / 入口 / 中点 | O(n) | O(1) | 快慢指针 |
| 倒数第 k / 删倒数第 k | O(n) | O(1) | 快先走 k 或 k+1 步 |
| 合并有序链表 | O(n+m) | O(1) | 哨兵尾插 |
| 回文判断 | O(n) | O(1) | 找中点 + 反转后半 |
| 相交判断 | O(n+m) | O(1) | 交换跑道 |

**所有链表操作几乎都能做到 O(1) 空间** —— 用 O(n) 空间的哈希/数组解法通常不是最优。
